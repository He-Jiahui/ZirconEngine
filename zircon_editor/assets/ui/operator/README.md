# Operator asset landing boundary

`contract/roles.contract.toml` is handwritten engineering authority.
The ZOP compiler/apply step owns generated `shell/*.zui`, `panels/*.zui`,
`components/*.zui`, `theme/zop_tokens.zui`, `icons/*.svg`, adjacent role sidecars
and `zop-bundle.lock.json`. Each generated document carries Penpot provenance.

No real Penpot bundle has been applied. This directory is not a selectable shell.
Do not hand-author a substitute screen or replace the working legacy shell before
plan 14 O0 and native role/visual tests are accepted.
