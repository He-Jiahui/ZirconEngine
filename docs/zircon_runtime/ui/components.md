# Runtime UI Component Inventory

This is the plan 06 M1.S1 baseline for the editor component library. It records the current L1 atom coverage against the seven Definition of Done gates from `06-component-library-mui.md`; it is an implementation inventory, not an acceptance claim.

## DoD Gates

Legend: `OK` means the current code has a usable owned implementation for the gate. `Partial` means the concept exists but still depends on another milestone, a Material showcase-only asset, or missing behavior. `Missing` means the gate has no owned implementation yet.

| Gate | Requirement | Current owner |
|---|---|---|
| Asset | A `.zui` asset exists in the Workbench primitive whitelist or the Material component showcase. | `zircon_editor/assets/ui/editor/components/workbench/primitives`, `zircon_editor/assets/ui/editor/material_components` |

| Test | Focused tests and showcase rows cover the contract. | component catalog tests, Material Lab, later contract scripts |

## Current Implementation Implications

- No L1 atom has all seven gates at `OK` yet. `Button` and `IconButton` are the closest runtime-owned path because the descriptors now expose focus, hover, press, and commit, and `state_reducer/button.rs` owns the retained interaction flags.
- Material showcase assets cover more components than the Workbench primitive whitelist. SearchInput, RangeSlider, Label, Icon, ProgressBar, Divider, Skeleton, NumberField, and TabStrip have now moved into the Workbench primitive whitelist, bringing the native component asset contract to 32 assets; remaining gaps are behavior, render/style parity, and higher-layer L2/L3/L4 components rather than missing L1 primitive shells.
- Reducer ownership is now split by behavior family: button interaction, semantic keyboard action/text, text-input validation timing, generic interaction flags, disclosure, numeric drag, popup/overlay flags, selection, collection mutation, reference drop/location behavior, and world-space transform/surface metadata live under `state_reducer/`. Future slices should continue this pattern for the remaining plan 03 text edit chain, deeper tab/choice behavior, and complex collection widgets.
- L2 collection groundwork is now represented in the same reducer structure: `state_reducer/windowing.rs` owns virtualized range aliases for `VirtualList`/`DataGrid` and page-window state for `Pagination`/`TablePagination`.
- Keyboard and focus completeness remains the dominant gap, but the semantic-keyboard reducer and host-route slices now cover activation, cancel, tab movement, RadioGroup/ToggleButtonGroup indexed movement, disabled-option skipping, ToggleButtonGroup multiple focused-option activation, Menu/MenuList indexed focus movement, Menu/MenuList first-letter and multi-character prefix focus movement with retained typeahead buffer reset semantics, explicit `TypeaheadExpired` expiry marking, host `TypeaheadTimer` scheduling/dispatch through `UiInputManager::tick(...)`, recursive Menu/MenuList `search_query` filtering with `filtered_option_ids`/`filter_no_results` retained state and submenu ancestor-path retention, Menu/MenuList submenu pending/open retained state and keyboard focus-scope cycling, TextField/Input/Textarea/SearchField/SourceEditor printable insertion with append fallback and explicit selection replacement/caret writeback, SearchField and Autocomplete query-backed host text-edit property routing, TextInput commit/blur/change validation timing with dirty/touched props, RangeSlider lower/upper focused-thumb keyboard stepping, value/percent mirror synchronization, nearest-thumb pointer track click/capture dispatch, drag-session property locking, default cross-thumb clamp, and configurable no-swap/swap active-thumb policy, MUI TextField ArrowLeft/Delete/End retained edit-state host routing plus active-selection Backspace collapse, word/shift/multiline caret combinations, pointer text selection, ABI IME disabled-to-Cancel routing, MUI TextField IME preedit/commit/cancel retained-state coverage, retained IME context hard-line/soft-wrap cursor and composition rect reporting, TextField render-extract preedit span injection, ListView/TreeView/Table/DataGrid indexed collection focus baseline, numeric step state, and the disabled host gate for explicit `KeyboardText` dispatch.
