# Plan Failure Handoff Skill Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add and validate a repository-local cross-plan failure/fix handoff lifecycle, then migrate the three open Editor M1 handoffs to it.

**Architecture:** A focused project child skill owns the behavioral rules, a reusable Markdown reference owns the artifact schema, and a standard-library Python validator enforces naming, provenance, routing, and return-link invariants. Existing plan records are migrated in place without changing their unresolved status or losing evidence.

**Tech Stack:** Markdown skills and plans, YAML frontmatter, Python 3 standard library, PowerShell invocation, Git.
