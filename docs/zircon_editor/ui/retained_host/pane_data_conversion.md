# Retained Host Pane Data Conversion

## 职责

`pane_data_conversion` 把 workbench host-window pane 数据转换成 retained-host contract 数据。它同时承接 native fallback pane、template runtime pane presentation、host component projection 和若干专用 pane（build export、module plugins、runtime diagnostics、performance timeline）的转换入口。

## 当前结构

- `mod.rs` 仍是 pane 转换的主入口，保留 `to_host_contract_*_pane` façade 与部分 legacy/native fallback 逻辑。
- `animation_projection.rs` 拥有 animation pane façade/native fallback、template-runtime animation sequence/graph payload 到 `AnimationEditorPaneData` 的 projection 分支与 string-list 转换。
- `component_showcase_projection.rs` 拥有 component showcase pane 的 template-runtime projection、builtin runtime fallback 和 retained host-model node projection 入口。
- `console_projection.rs` 拥有 console pane façade/native fallback、legacy console node id 修正、template-runtime console payload 到 `ConsolePaneData` 的 projection 分支、runtime host-model 节点投影和 payload status fallback。
- `generated_bottom_projection.rs` 拥有 generated-bottom pane 的 template-runtime node projection、native fallback 和 status 装配入口。
- `hierarchy_projection.rs` 拥有 hierarchy pane façade/native fallback、template-runtime hierarchy payload 到 `HierarchyPaneData` 的 projection 分支、scene-node DTO 转换和 template node selection/empty-state 标记。
- `inspector_fields.rs` 拥有 inspector fallback 字段、plugin component 降级提示、字段 frame 计算、文本/数字/按钮节点生成。
- `inspector_pane_tests.rs` 拥有 inspector pane projection 的模块内行为测试、fixture 与 node lookup helper，父 `mod.rs` 只保留 `#[cfg(test)]` 挂载点。
- `inspector_projection.rs` 拥有 inspector pane façade/native fallback、template-runtime inspector payload 到 `InspectorPaneData` 的 projection 分支、payload 字段读取、plugin component payload 到 view-data 的转换和 runtime host-model 节点投影。
- `model_projection.rs` 拥有非 template-node `ModelRc<T>` 到 retained-host `ModelRc<U>` 的泛型映射 helper，当前由 build export、module plugins、performance timeline owner 直接引用。
- `build_export/` 拥有 Build/Export pane façade、target DTO 转换、template presentation fallback 和模块内行为测试；`build_export/target_rows/` 拥有 fallback target-row projection，按 metrics、identity、node、actions、row 和 façade entry 分层。
- `build_export_wizard_panel.rs` 拥有 desktop export wizard panel 的 retained node projection。
