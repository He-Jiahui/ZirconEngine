# Workbench Run Mode Menu

## Purpose

`run_mode_menu.rs` is the narrow adapter from the componentized Workbench Run Mode popup to the editor's typed play-session contract. It maps supported popup row ids to `MenuAction::SelectPlayMode(PlayKind)` and does not own popup geometry, play lifecycle state, or backend execution.

## Behavior

The authored menu defaults to Play In Editor. Selecting Play In Editor or Simulate closes the popup, moves the single persistent `checked` flag to that row, dispatches a canonical menu binding, records the typed editor event, and updates `PlaySessionController::preferred_kind()`. The existing Play button then constructs its `PlayStartRequest` from that preference.

Before the real Run Mode trigger opens, `control.rs` asks this owner to synchronize the menu value and checked row from the controller preference. The controller is read only for that trigger click, not for every toolbar command. Rebuilding the retained bridge therefore cannot silently reset a previously selected Simulate preference back to the template default.

Standalone and Network Preview are declared disabled. They stay visible as future capability discoverability, but cannot change the selected value or dispatch an engine action until a matching typed backend contract exists.

The generic popup owner only treats a menu as single-choice when its template explicitly declares `selection_mode = "single"`. Ordinary command menus and mixed command/choice menus therefore keep their existing behavior. Choice-row normalization removes transient focus/hover/press flags, preserves icons, danger/disabled flags and shortcuts, removes the old check, and adds one check to the selected row.

## Ownership

- `run_mode_menu.rs` owns row-id to `PlayKind` mapping.
- `popup_state.rs` owns selection and popup close behavior.
- `popup_primitives.rs` owns structured menu-flag normalization.
- `MenuAction` and the event executor own typed dispatch and status feedback.
- `PlaySessionController` owns the next-run preference and lifecycle mode.
