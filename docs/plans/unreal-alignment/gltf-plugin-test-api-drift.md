# glTF plugin: existing library tests refer to removed importer seams

**Draft — diagnosis only.** No production or test repair is included. This is separate from the generated tangent fix in [#141](https://github.com/He-Jiahui/ZirconEngine/pull/141).

1. **Difference.** The [extension tests](../../../zircon_plugins/gltf_importer/runtime/src/tests/material_extensions.rs#L1-L174), [normals hot-path fixture](../../../zircon_plugins/gltf_importer/runtime/src/tests/hotpaths.rs#L10-L25), and [mesh lookup](../../../zircon_plugins/gltf_importer/runtime/src/tests/geometry_convergence.rs#L114-L123) still reference old test seams. Unreal's Interchange glTF translator checks unsupported required extensions in the actual translation path (`Engine/Plugins/Interchange/Runtime/Source/Import/Private/Gltf/InterchangeGltfTranslator.cpp:620–641`), and the mesh factory owns authored versus generated normals/tangents (`Engine/Plugins/Interchange/Runtime/Source/Parsers/GLTFCore/Private/GLTFMeshFactory.cpp:539–590`). This is an ownership comparison, not evidence that the two engines support the same extensions or use the same buffer lifetimes.
2. **Effect.** The plugin `--lib` test target exits during compilation with nine errors for missing symbols/types and the obsolete `ImportedAssetEntry.uri` field. No named plugin library test ran. The reported lines predate #141; the engine's runtime tests and the plugin's separately scoped integration target are different evidence.
3. **Cause and UE evidence.** The ZE plugin now calls the [shared decoder](../../../zircon_runtime/src/asset/importer/ingest/gltf_decode.rs#L53-L109) and [indexed source projection](../../../zircon_runtime/src/asset/importer/ingest/indexed_mesh_projection.rs#L32-L69); stale fixtures still expect the removed private helpers. UE validates required extensions before entering material/geometry translation and handles missing normals with fallback geometry, rather than modeling an isolated legacy helper.
4. **Rust direction.** Reuse the current production importer and error policy; qualify the render DTO type and use the published locator. The borrowed-normal assertion needs separate investigation: the current shared projector clones authored data, so a test-only symbol replacement cannot truthfully preserve the old `Cow::Borrowed` contract. Do not make a dummy helper or weaken the assertion to make the target compile.
5. **Interface/ECS boundary.** This concerns import test scope and intermediate buffer ownership, not ECS, shader ABI, asset identifiers or Prefab. Unreal's output geometry is a behavioral reference, not an oracle for Rust allocations.
6. **Concrete ZE change and gate.** First audit the old helper contracts against the current production owners, including the complete-vs-short normal input and extension-error cases. Restore each justified assertion in the existing harness and reproduce its behavior before proposing any shared runtime changes. This Draft contains only the problem note; do not use it to bypass the blocked plugin library suite.
