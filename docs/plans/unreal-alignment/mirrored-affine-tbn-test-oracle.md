# Mirrored affine TBN: compare the reconstructed basis, not a sheared direction

**Draft — problem definition only.** The unchanged CPU control from [BD02](https://github.com/He-Jiahui/ZirconEngine/pull/135) fails even when the renderer's instance affine tests pass.

1. **Difference.** The [ZE CPU fixture](../../../zircon_runtime/src/graphics/scene/renderer/mesh/build/tests/gpu_scene_sync.rs#L223-L253) judges a reconstructed bitangent against normalized `A * B`; this includes tangential shear. UE reconstructs the bitangent from `cross(N,T)` and a sign. In this example ZE's production reconstruction already uses that rule.
2. **Effect.** The old fixture rejects a correct `[0,1,0]` against `[0.08304548,0.9965458,0]`. This is a false failure and can misdirect a renderer fix; it is not an observed normal-map shading or frame-time defect.
3. **Cause and UE evidence.** `Engine/Shaders/Private/LocalVertexFactory.ush:650–659,765–768` reconstructs the local basis and multiplies the authored tangent sign by instance determinant sign. `Engine/Shaders/Private/MaterialTemplate.ush:4757–4766` derives the third world basis vector by cross product and the resulting sign. Under the ZE fixture's exact affine, the transformed bitangent is `(0.25,3,0)`, which is not perpendicular to the transformed tangent. No identical UE mirrored-shear automation case was found; this is a source-derived oracle, not a UE numeric port.
4. **Rust approach.** Project the independently transformed authored bitangent perpendicular to `T'` before comparing it to the reconstructed `B'`. Validate basis orientation for both authored signs. Also use a normal for which the linear normal direction differs from the inverse-transpose direction.
5. **Interface/ECS boundary.** ZE's [normal path](../../../zircon_runtime/src/graphics/scene/renderer/mesh/shaders/zr_gpu_scene.wgsl#L184-L230) preserves the full affine; UE's ordinary attachment state is not an exact shear oracle. This single-vertex CPU expectation does not change or re-orthogonalize the material's interpolated pixel basis, GPU layouts, mesh generation, or ECS.
6. **Concrete change.** Keep the existing classifier and shader-equivalent CPU fixture, replace only the reference comparison, and retain its strict tolerance. Revalidate it alongside the existing normal/handedness controls. A separate mirrored-UV asset generator control is independently failing and is not fixed here.
