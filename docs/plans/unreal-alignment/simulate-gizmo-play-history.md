# A changed Simulate gizmo release borrows an absent Edit preview reservation

Problem-only Draft. This is a release/history issue even for a **root** with no parent or shear. It is independent of [#206](https://github.com/He-Jiahui/ZirconEngine/pull/206), whose witness stops at Preview/Cancel and concerns world versus local coordinates. Nothing here records a new running test, behavioral RED, production fix, or product acceptance.

## Reachable path and consequence

On a validated Simulate frame, the [retained viewport](../../../zircon_editor/src/ui/retained/app/viewport/pointer_event.rs#L75-L106) routes a primary [pointer Up to Commit](../../../zircon_editor/src/ui/host/play_gizmo.rs#L159-L185). [Play Begin](../../../zircon_editor/src/ui/host/play_gizmo.rs#L244-L298) starts the real Runtime editor transform interaction and stores `ActivePlayGizmoInteraction` plus a viewport HandleTool drag; it does not start the authoring `InteractiveTransformSession`. [Entering Play](../../../zircon_editor/src/ui/workbench/state/editor_state_play_mode.rs#L31-L48) takes the [exclusive owner transition](../../../zircon_editor/src/ui/workbench/startup/editor_state_project.rs#L215-L228), which [cancels and takes the Edit preview](../../../zircon_editor/src/ui/workbench/state/editor_state_viewport.rs#L270-L279).

[Release](../../../zircon_editor/src/ui/host/play_gizmo.rs#L424-L511) sends V1 `Commit(expected=current, target=current)` first. [Runtime dispatch](../../../zircon_runtime/src/dynamic_api/session/events.rs#L228-L245) holds the Level's World/epoch together. Its [active write](../../../zircon_runtime/src/dynamic_api/session/editor_transform.rs#L89-L115) validates the interaction and local CAS, closes the Runtime gesture on success, and does not treat a same-value write as an error. The host then clears its active drag. Only when the local value changed does it create an already-applied Play command and call [`execute_gizmo_scene_command`](../../../zircon_editor/src/ui/workbench/state/editor_state_apply_intent.rs#L215-L246). That helper selects the active history but unconditionally extracts a reservation from the **Edit** `interactive_transform`. None returns `GizmoTransactionError::TransactionContextMissing` before any Play history can be opened, even though there is a valid `CoreEditContext` and Play gateway.

The [failure compensation](../../../zircon_editor/src/ui/host/play_gizmo.rs#L642-L688) reads the same gateway/entity/epoch, then sends `Apply(expected=current, target=initial)` if the value still matches. For an otherwise stationary root, source predicts successful Preview, then a history error and a return to the initial transform on release. If the value or epoch diverges, compensation must not clobber it; the reported rollback failure is distinct. An unchanged Up does not enter the erroneous history branch. A provisional Runtime movement is not evidence of a retained user edit.

## Local Unreal comparison and ZE ownership

Local Unreal [normalizes manipulable typed elements against PlayWorld in SIE](<E:/Git/ZirconEngine/dev/UnrealEngine/Engine/Source/Editor/UnrealEd/Private/LevelEditorViewport.cpp#L4274-L4286>), and [typed elements must belong to that world](<E:/Git/ZirconEngine/dev/UnrealEngine/Engine/Source/Editor/EditorFramework/Private/Subsystems/EditorElementSubsystem.cpp#L63-L91>). [Viewport tracking begins manipulation and starts a pending transaction](<E:/Git/ZirconEngine/dev/UnrealEngine/Engine/Source/Editor/UnrealEd/Private/LevelEditorViewport.cpp#L3697-L3759>); [tracking stop ends or cancels its own transaction according to change](<E:/Git/ZirconEngine/dev/UnrealEngine/Engine/Source/Editor/UnrealEd/Private/LevelEditorViewport.cpp#L3817-L3863>). Separate [Keep Simulation Changes](<E:/Git/ZirconEngine/dev/UnrealEngine/Engine/Source/Editor/LevelEditor/Private/LevelEditorActions.cpp#L2683-L2717>) is an explicit copy to editor counterparts, not normal gizmo release. UE can [record eligible transactional PIE objects](<E:/Git/ZirconEngine/dev/UnrealEngine/Engine/Source/Runtime/CoreUObject/Private/UObject/UObjectGlobals.cpp#L3207-L3233>), sets an [undo barrier on PIE entry](<E:/Git/ZirconEngine/dev/UnrealEngine/Engine/Source/Editor/UnrealEd/Private/PlayLevel.cpp#L2974-L2991>) and [resets the transaction buffer if it still refers to PIE objects at cleanup](<E:/Git/ZirconEngine/dev/UnrealEngine/Engine/Source/Editor/UnrealEd/Private/PlayLevel.cpp#L500-L509>). The comparison is about active-world routing, gesture custody and isolation, not identical UE PIE undo behavior or `FTransform` math.

ZE already has a [volatile Play history context](../../../zircon_editor/src/ui/workbench/state/scene_document_binding.rs#L27-L36), [already-applied command with local V1 CAS Undo/Redo](../../../zircon_editor/src/core/editing/command/play_transform.rs#L40-L82), [dispatch bound to the Play world route](../../../zircon_editor/src/core/editing/context.rs#L231-L250), and [terminal Play history disposal before gateway detach](../../../zircon_editor/src/ui/host/editor_host_event_controller/runtime_shutdown.rs#L222-L260). Release must use that actual Play custody, including transaction staging/retention policy, a single undo record, and stale gateway/epoch checks. Do not fabricate an Edit reservation, bypass retention, write the authoring World, or silently ignore failure. Any compensation remains compare-and-set. Keep the local V1 wire, Runtime Scene authority, Editor Edit preview semantics, #206's affine transport, and all gizmo math unchanged here.
