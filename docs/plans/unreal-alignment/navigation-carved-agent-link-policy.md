# Navigation: separate an agent's link policy from a live carved TileCache

**Problem-only Draft.** Based directly on `main@e89349ca51b4e9d024c194cd3bdf645bd25b6c37`; there is no new test, measured agent failure or production edit yet. Independent of [#182](https://github.com/He-Jiahui/ZirconEngine/pull/182) (obstacle center, only the collector hunk), [#187](https://github.com/He-Jiahui/ZirconEngine/pull/187) (coincident path metadata) and [#188](https://github.com/He-Jiahui/ZirconEngine/pull/188) (ordinary ground adjacency).

1. **Difference.** ZE [derives a query asset per agent](../../../zircon_plugins/navigation/runtime/src/manager/traversal/mod.rs#L27-L51). Opt-out strips all links; otherwise only authored automatic links remain. The [carved runtime path](../../../zircon_plugins/navigation/runtime/src/runtime_obstacles.rs#L24-L51) uses that projection at TileCache construction, but looks up later queries only by `NavMeshHandle`. The [ordinary explicit query](../../../zircon_plugins/navigation/runtime/src/manager/query.rs#L8-L25) is separate; it does not seed this cache.
2. **Consequence to reproduce.** With a continuous, harmless live carver, a first opt-out agent may leave the next allowed agent without its only valid crossing. Reversing caller order may expose the previous agent's link to the next opt-out agent. [The real tick](../../../zircon_plugins/navigation/runtime/src/manager/tick.rs#L99-L123) can dispatch that path point's ID against the full asset, so an agent may enter a traversal rather than merely receive an incorrect route. Neither movement, phase nor event effect is claimed before the test runs.
3. **Cause and local Unreal comparison.** In actual `dev/UnrealEngine`, `Engine/Source/Runtime/NavigationSystem/Private/NavMesh/PImplRecastNavMesh.cpp:436–445,1320–1343` supplies a link filter with the current search owner, against the same native mesh. `Engine/Source/Runtime/Navmesh/Public/Detour/DetourNavMeshQuery.h:811–824` checks specific off-mesh user IDs. `Private/Detour/DetourNavMeshQuery.cpp:1733–1745` rejects disallowed link neighbors during the search, not after selecting a route. `Engine/Source/Runtime/AIModule/Private/Navigation/PathFollowingComponent.cpp:955–965,1455–1494` shows link-identity-based start/finish dispatch; it does not establish ZE's trajectory or cache layout.
4. **Rust/native decision after RED.** Preserve live obstacle bindings and apply the current agent's policy before path search (or use two clearly bounded compatible topology variants). Keep walkable and per-area semantics, including an automatic link sharing the same area as a manual link. Do not hide the problem by ignoring events after an invalid route, globally masking Jump, rerasterizing by agent identity, or changing native link endpoints. Review unsupported link-cost behavior and cache cleanup before selecting the smallest correction.
5. **Interface/ECS.** `NavMeshAgentDescriptor::auto_traverse_links` and asset `traversal_mode` are independent of baked topology and `NavMeshHandle`; ZE reports each stage with actual agent/mesh/owner/link/endpoint identity. This is a movement-query policy issue, not an affine change, not a request to copy UObject callbacks, and not a baked schema change.
6. **Test to freeze.** Adapt the existing [two-island mesh](../../../zircon_plugins/navigation/runtime/src/tests/support.rs#L8-L42), [opt-out tests](../../../zircon_plugins/navigation/runtime/src/tests/manager.rs#L305-L360), and [jump stages](../../../zircon_plugins/navigation/runtime/src/tests/off_mesh.rs#L14-L40) using the actual manager/tick and typed world components. Run two fresh worlds, opposite first/second-agent order, same handle, same persistent carver and interior forward endpoints; no-carve results and first-use policies are controls. Check native ground endpoints and ID, agent blockage/position plus Started/Completed and arch/landing. Use local UE `Engine/Source/Developer/NavigationTestSuite/Private/NavMeshPathfindingTest.cpp:94–126,132–160` for real route/endpoint/filter predicates, not a claim of a matching UE regression or executed Unreal binary.
