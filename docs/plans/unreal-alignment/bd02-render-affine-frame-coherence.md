# BD02: keep the mesh frame's world transform and bounds coherent

**Draft — tests only.** The initial commit opened the problem review. This branch now carries two prepared-frame CPU regressions, the Unreal same-input bounds control, and two renderer regressions; no engine behavior has changed.

1. **Difference.** In ordinary Unreal static meshes, component transform supplies both the render matrix and bounds. ZE's World and persistent RenderScene retain `WorldMatrix`, while the [mesh extraction path](../../../zircon_runtime/src/scene/world/render.rs) projects it back to TRS before [CPU bounds projection](../../../zircon_runtime/src/graphics/visibility/culling/mesh_bounds.rs) and [model-matrix preparation](../../../zircon_runtime/src/graphics/mesh/build/extend_pending_draws_for_mesh_instance.rs).
2. **Effect.** The local tests-only combination of this PR and [the compilation prerequisite (#137)](https://github.com/He-Jiahui/ZirconEngine/pull/137) reproduced both issues: opposite shear matrices shared a stable key and revision; the CPU culler lost an instance with an in-frustum vertex on both full and sparse frames. Neither lost pixels nor stale GPU output have been observed.
3. **Cause and Unreal reference.** TRS decomposition loses shear, and a sphere scaled by the largest column length is not conservative for arbitrary shear. Unreal `GetRenderMatrix` (`Engine/Source/Runtime/Engine/Private/Components/PrimitiveComponent.cpp:1267–1270`), `CalcBounds` (`Engine/Source/Runtime/Engine/Private/Components/StaticMeshComponent.cpp:665–679`), and the update payload (`Engine/Source/Runtime/Renderer/Private/RendererScene.cpp:1630–1641`) derive and carry matrix and bounds together. The proxy stores both and compares the matrix itself (`Engine/Source/Runtime/Engine/Private/PrimitiveSceneProxy.cpp:905–971`). Ordinary UE attachment is TRS (`Engine/Source/Runtime/Engine/Private/Components/SceneComponent.cpp:727–748`), so it is not a shear parity oracle. The affine bounds reference is `TBox::TransformBy(TMatrix)` (`Engine/Source/Runtime/Core/Public/Math/Box.h:870–918`).
4. **Rust direction.** Keep the same frame-owned matrix for bounds and draw preparation, and derive their revision from that value. Do not change just the culler or apply a maximum-column radius to shear.
5. **Interface and ECS boundary.** Preserve the World hierarchy, shared frame ownership, and existing GPU instance layout. A sparse scene-change journal is not a full transform table. Verify editor/capture adapters and previous-frame HZB before claiming broader coverage.
6. **Landing order.** Replay the tests-only baseline on this branch. Verify a bounded production fix, rerun the frozen tests and an appropriate renderer check, and merge only when the evidence supports it. No Prefab changes.

This test follows the same UE render update contract above, not UE's instance packing format.
