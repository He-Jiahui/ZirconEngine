# BD02: keep the mesh frame's world transform and bounds coherent

**Draft — tests only.** The initial commit opened the problem review. This branch now carries two BD02 regression fixtures and one Unreal same-input bounds control; no engine behavior has changed.

1. **Difference.** In ordinary Unreal static meshes, component transform supplies both the render matrix and bounds. ZE's World and persistent RenderScene retain `WorldMatrix`, while the [mesh extraction path](../../../zircon_runtime/src/scene/world/render.rs) projects it back to TRS before [CPU bounds projection](../../../zircon_runtime/src/graphics/visibility/culling/mesh_bounds.rs) and [model-matrix preparation](../../../zircon_runtime/src/graphics/mesh/build/extend_pending_draws_for_mesh_instance.rs).
2. **Effect.** A local CPU reproduction found distinct shear matrices with the same stable mesh key and transform revision. Stale render state and an incorrectly excluded mesh are distinct risks. That run used a separate investigation worktree. The visibility fixture on this branch uses the actual World identity, but neither a visibility failure on this branch nor lost pixels/stale GPU output have been observed.
3. **Cause and Unreal reference.** TRS decomposition can lose shear. Unreal `UPrimitiveComponent::GetRenderMatrix`, `UStaticMeshComponent::CalcBounds`, `FScene::UpdatePrimitiveTransformInternal`, and `FPrimitiveSceneProxy::SetTransform` publish the render matrix and corresponding bounds together; `WouldSetTransformBeRedundant_AnyThread` compares the matrix itself. An ordinary UE attachment uses TRS, so it is not a shear parity oracle. `TBox::TransformBy(TMatrix)` and `AABBTests.TestTransformAABB_ScaleRotateTranslate` are the bounds references.
4. **Rust direction.** Keep the same frame-owned matrix for bounds and draw preparation, and derive their revision from that value. Do not change just the culler or apply a maximum-column radius to shear.
5. **Interface and ECS boundary.** Preserve the World hierarchy, shared frame ownership, and existing GPU instance layout. A sparse scene-change journal is not a full transform table. Verify editor/capture adapters and previous-frame HZB before claiming broader coverage.
6. **Landing order.** Replay the tests-only baseline on this branch. Verify a bounded production fix, rerun the frozen tests and an appropriate renderer check, and merge only when the evidence supports it. No Prefab changes.
