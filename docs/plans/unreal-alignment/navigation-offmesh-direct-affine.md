# Navigation: inverse-affine point writeback for off-mesh traversal

**Problem-only Draft**, based on `main@e89349ca51b4e9d024c194cd3bdf645bd25b6c37`. No behavioral result, integration test or production edit yet. Independently scoped to direct writes during `Started`, `Traverse`, and `Completed`, not the ordinary approach/facing changes in [#146](https://github.com/He-Jiahui/ZirconEngine/pull/146) / [#172](https://github.com/He-Jiahui/ZirconEngine/pull/172), link direction [#190](https://github.com/He-Jiahui/ZirconEngine/pull/190), or authored position [#181](https://github.com/He-Jiahui/ZirconEngine/pull/181).

1. **Difference.** [ZE stage advancement](../../../zircon_plugins/navigation/runtime/src/manager/traversal/advance.rs#L38-L90) supplies world entry, arc and landing points. [Direct writeback](../../../zircon_plugins/navigation/runtime/src/manager/tick.rs#L245-L287) passes those points and projected world rotation/scale to the [authored-local setter](../../../zircon_runtime/src/scene/world/hierarchy.rs#L132-L151). A successful local write can report Started/Completed although actual world position missed the event endpoint; copying projected rotation/scale may change the entire child basis even with turning disabled.
2. **To measure.** Capture the actual WorldMatrix translation at both events and all arc frames, and compare each authored rotation/scale and the entity's own world linear basis with their pre-traversal values. Root and translated-parent controls distinguish basis loss from writing coordinates in the wrong space. Event identity is necessary but cannot stand in for readback. Avoid ordinary movement while arming the approach so ordinary writeback remains out of scope.
3. **Actual Unreal contract.** Local `Engine/Source/Runtime/Engine/Private/Components/MovementComponent.cpp:532–539` routes a world delta to the component. `Engine/Source/Runtime/Engine/Private/Components/SceneComponent.cpp:3449–3483,3293–3356` computes the new world point, inverse-transforms through the attachment parent and writes relative location. `Engine/Source/Runtime/AIModule/Private/Navigation/PathFollowingComponent.cpp:1455–1494` ties custom link callbacks to the actual segment destination and owner. Neither UE FTransform nor UE callback behavior provides the ZE shear or arc oracle.
4. **ZE/Rust target after real RED.** Convert only the direct world point through the full inverse parent affine transform for a parented agent with `update_rotation=false`, preserving authored child basis and native event order. [ZE's full matrix chain](../../../zircon_runtime/src/scene/world/derived_state.rs#L502-L531), [Three.js r180 `worldToLocal`](https://github.com/mrdoob/three.js/blob/r180/src/core/Object3D.js), and [Unity Entities transform concepts](https://docs.unity3d.com/Packages/com.unity.entities@1.3/manual/transforms-concepts.html) define the affine semantics. Root and active-facing policies remain unchanged; exact general world heading through a shear is separate. Propagate inverse/write failures through the existing event gate.
5. **Interface/ECS.** The traversal engine requests world coordinates; `LocalTransform` is authored, `WorldMatrix` authoritative, and `world_transform()` is a compatibility projection. Keep the world-stage contract, motion parameters, link/owner/handle, displacement accounting and event ABI; place this conversion only at the direct write boundary.
6. **Test first.** Reuse the existing [real jump-stage case](../../../zircon_plugins/navigation/runtime/src/tests/off_mesh.rs#L14-L40) and [event write gate](../../../zircon_plugins/navigation/runtime/src/manager/traversal/tests/cases.rs#L16-L59). The local UE `Engine/Source/Runtime/Engine/Private/Tests/EngineAutomationTests.cpp:2045–2085` checks attachment world and relative values and that the parent is unchanged; adapt those assertions, not the TRS expectation or a UE binary run. Freeze a verified native one-way A=(1,0,0)→B=(7,0,0) route from the noncoincident near-entry world point S=(.94,0,.08). Arming must not move the agent. Use a fixed clock for entry, first arc and exact landing writes. A nested `diag(2,1,1)*Ry45` case must match the root trajectory in point space while preserving its own sheared basis, never equating the two world matrices.
