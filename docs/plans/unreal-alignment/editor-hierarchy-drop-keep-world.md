# Edit Hierarchy drops change the world pose of the moved subtree

Problem-only Draft. This records the live Edit-mode Hierarchy action and its intended contract. No new regression has been executed, and no production code, test, interface, or acceptance gate changes are included.

## Difference, effect, and cause

The retained [mouse release](../../../zircon_editor/src/ui/retained/app/hierarchy_pointer/events/drag.rs#L61-L87) dispatches [a hierarchy event](../../../zircon_editor/src/ui/host/editor_event_execution/hierarchy_event.rs#L9-L16) and [the standard `SetParents` intent](../../../zircon_editor/src/ui/workbench/state/editor_state_apply_intent.rs#L117-L137). It deduplicates selected roots and uses one editor history transaction, but [captures only a new parent](../../../zircon_editor/src/core/editing/command.rs#L836-L845). [Command execution](../../../zircon_editor/src/core/editing/command.rs#L904-L930) calls [`World::set_parent_checked`](../../../zircon_runtime/src/scene/world/hierarchy.rs#L96-L130), correctly keeping authored local TRS. The actual drag does not supply the KeepWorld policy expected by [RSH-P1-057](../../../docs/plans/optimize/zircon_runtime/62-runtime-scene-hierarchy-transform-propagation-reparent-activation-mobility-visibility-bounds-render-product-integration-review.md#L264-L275).

For old parent world X=1, new parent X=4, and moved root local X=2, changing only the parent moves the whole subtree from root world X=3 to X=6. An exact KeepWorld drop should set the root local X to −1 and keep its published world matrix unchanged. [The existing Scene control](../../../zircon_runtime/src/scene/world/tests/dirty_state.rs#L21-L72) explicitly expects 3→6 from the checked KeepLocal API; it must keep passing. [The current pointer and undo test](../../../zircon_editor/src/ui/retained/app/tests/drag_sources/hierarchy_gesture.rs#L195-L236) only compares parents, events and history, not the world matrices.

## Local Unreal source and ZE ownership

The local Unreal [Scene Outliner attach loop](<E:/Git/ZirconEngine/dev/UnrealEngine/Engine/Source/Editor/SceneOutliner/Private/ActorMode.cpp#L896-L939>) calls [`UEditorEngine::ParentActors`](<E:/Git/ZirconEngine/dev/UnrealEngine/Engine/Source/Editor/UnrealEd/Private/EditorEngine.cpp#L4232-L4267>), whose component attach rule is `KeepWorldTransform`. Its [detach branch](<E:/Git/ZirconEngine/dev/UnrealEngine/Engine/Source/Editor/SceneOutliner/Private/ActorMode.cpp#L844-L861>) uses the corresponding explicit detachment rule. [The SceneComponent path](<E:/Git/ZirconEngine/dev/UnrealEngine/Engine/Source/Runtime/Engine/Private/Components/SceneComponent.cpp#L2524-L2539>) obtains a socket-relative `FTransform`, then [writes the individual relative channels](<E:/Git/ZirconEngine/dev/UnrealEngine/Engine/Source/Runtime/Engine/Private/Components/SceneComponent.cpp#L2551-L2607>). This is a reference for the edited object's placement and transaction boundary, **not** for inherited affine math, sockets, or altering an ancestor to accept a cycle.

ZE's [Scene transform propagation](../../../zircon_runtime/src/scene/world/derived_state.rs#L656-L682) owns `parent_world * local_matrix`. A drag must carry explicit placement intent from the Edit action; Scene must own topology/transform preflight and mutation. Exact KeepWorld requires `L_new = inverse(P_new) * W_old` (detach: `L_new = W_old`). The protected authored `LocalTransform` is TRS today; a full result needing local shear cannot be silently decomposed or approximated. For example, reparenting world `Rz(π/4)` under `diag(2,1,1)` would require local columns with dot product `3/8`, rather than the orthogonal columns of TRS. The initial contract should reject this case without modifying the hierarchy, local values or history. Exact support for authored affine locals would be a distinct storage/API decision. Keep old `set_parent_checked`, prefab local placement, Simulate Move, and editing of other gizmos out of this change. No copied UE `FTransform` and no new C ABI proposed.
