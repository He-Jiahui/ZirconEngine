# Navigation link and bridge endpoints drop hierarchy shear before Detour

**Draft — frozen native behavioral RED, before production change.** Baseline `main@e89349ca51b4e9d024c194cd3bdf645bd25b6c37`. This issue concerns link/bridge endpoints, not #173's input triangles, #172's agent facing or #158's registry ownership. The problem-only note was published before test changes.

1. **Difference.** The ZE [shared endpoint resolver](../../../zircon_plugins/navigation/runtime/src/off_mesh_connections.rs#L164-L177) converts the World pose to a TRS and back before projecting a local point. The caller is both [an authored link](../../../zircon_plugins/navigation/runtime/src/off_mesh_connections.rs#L40-L76) and [bridge lane generation](../../../zircon_plugins/navigation/runtime/src/off_mesh_connections.rs#L98-L150). UE's `FOffMeshData::AddLink` resolves `Left`/`Right` into world points before establishing Detour link parameters (`Engine/Source/Runtime/NavigationSystem/Private/NavMesh/RecastNavMeshGenerator.cpp:1413–1436`). UE starts with an `FTransform`; this is the placement boundary to compare, not a shear oracle.
2. **Impact.** For full `diag(2,1,1) * Ry(45°)`, authored `8X` projects to `(8√2,0,-4√2)` relative to its anchor. Old baked link start `(9.242340,0,-8.485282)` instead of `(11.313708,0,-5.656854)`, with **3.5057914** maximum point error in both the link and bridge cases. Both islands permit local routes, but both sheared cases return native `NoPath` across the gap even though the asset contains the correct count of link rows. UE Detour (`Engine/Source/Runtime/Navmesh/Private/Detour/DetourNavMesh.cpp:1490–1532`) separates nearest-poly selection and horizontal radius rejection; ZE Detour uses the same distinction.
3. **Cause and source.** The [actual World affine chain](../../../zircon_runtime/src/scene/world/derived_state.rs#L502-L531) already has the full matrix; the resolver unnecessarily round-trips through a compatibility representation. [Production direct-bake preparation](../../../zircon_plugins/navigation/runtime/src/manager/bake.rs#L415-L446) captures the computed links and [embeds them](../../../zircon_plugins/navigation/runtime/src/manager/bake/asset.rs#L67-L85) in the baked asset. The [native ABI conversion](../../../zircon_plugins/navigation/native/src/asset_ffi.rs#L52-L64) only reads their coordinates, area, direction, radius and ID; native [start snap](../../../zircon_plugins/navigation/native/vendor/recastnavigation/Detour/Source/DetourNavMesh.cpp#L565-L589) applies the radius after that conversion. No later stage repairs an incorrect world point.
4. **Rust direction.** After qualified RED, test a substitution of `world_matrix(anchor)` for the TRS round trip in the **one shared point resolver**, with the prior identity fallback on unavailable anchor. Keep start/end addressing, width-to-radius policy, motion/cost/direction, and the bridge side/lane algorithm, which should receive the corrected two anchor points. Do not alter the geometry collectors, asset publication fences, native ABI, or Core `Driver` rules.
5. **Interface/ECS.** ZE component descriptors can choose owner-local points or explicit external anchor entities. UE link data projects owner-local points with its navigation-relevant transform and flags. Maintain ZE's addressing and serde schema; only the resolved world rows change. Select a real `LevelSystem` and use the existing direct bake authority for the regression; a successful direct bake is not proof that #158's separate host registration works.
6. **Concrete gate.** Adapt actual UE `System.Navigation.NavMesh.Pathfinding.PathHasPoints` (`Engine/Source/Developer/NavigationTestSuite/Private/NavMeshPathfindingTest.cpp:94–126`) for path success and correct endpoints, with [ZE native disconnected and link-ID controls](../../../zircon_plugins/navigation/native/src/tests/path.rs#L49-L79) and [existing authoring cases](../../../zircon_plugins/navigation/runtime/src/tests/bake.rs#L145-L263). Bake two rigid Box floors around the independent analytic start/end, separated by about `24 m`; test owner and external anchor transforms and the two real bridge lanes. Rigid projected placement and link-free disconnection are controls. Require nonempty correct geometry, exact published endpoints, native Detour link ID and final path ending near the other island (not a partial path). Use the existent [native-only TileCache query path](../../../zircon_plugins/navigation/native/src/tile_cache.rs#L104-L159), which [builds one layer from the baked asset](../../../zircon_plugins/navigation/native/native/detour_tile_cache.cpp#L455-L515). A flag alone from a generic query can also be produced by Rust fallback, so it does not qualify native evidence. No identical UE link-specific automation or Unreal binary execution is claimed.
