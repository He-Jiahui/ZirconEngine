# Registered fixed-step writeback rejects a same-World transform revision

**Draft — measured unchanged-main RED.** Production is exactly ZE `main@e89349ca51b4e9d024c194cd3bdf645bd25b6c37`; only the problem note and frozen test cases are added. Earlier observations with [#198](https://github.com/He-Jiahui/ZirconEngine/pull/198) and [#145](https://github.com/He-Jiahui/ZirconEngine/pull/145) are separate from the isolated main result.

## Difference and consequence

ZE [registers a solver step and a scene writeback as fixed stages](../../../zircon_plugins/physics/runtime/src/runtime_system.rs#L47-L60). The [writeback system](../../../zircon_plugins/physics/runtime/src/runtime_system.rs#L139-L155) applies the same-World snapshot under a replacement-epoch guard. Updating a changed pose through the normal [authored transform entry](../../../zircon_runtime/src/scene/world/hierarchy.rs#L132-L150) legitimately changes the [World synchronization revision](../../../zircon_runtime/src/scene/world/generation.rs#L80-L93) and invalidates [affected component/derived state](../../../zircon_runtime/src/scene/world/typed_api/component_mutation_effects.rs#L34-L77). However, the [fixed stage and commit checks](../../../zircon_runtime/src/scene/module/world_driver.rs#L48-L125) compare against the frame's earlier content revision, and reject a normal in-place change as a generation mismatch. [Replacement identity](../../../zircon_runtime/src/scene/level_system.rs#L239-L288) and pinned schedule execution are separate concepts. Aborting the time transaction [does not roll back World writes](../../../zircon_runtime/src/scene/world_time/controller.rs#L373-L402).

In real registered ZE/Jolt tests, one root Dynamic sphere (no parent, shear, collider offset, gravity, angular motion, damping or collisions) produced `Stage(FixedPostUpdate)`: **expected world generation 7, found 8, committed steps 0, remaining debt 15.625 ms**. Same failure on local `d935f87262c3c4c318199966a09ab386cf48d7be` (exact #198 producer, original applier) and `74b8dbac9eeb898ee87d05c5f6edbf40169f7d4d` (that producer plus exact #145 applier). The intact root fixture checks the pre-tick valid/centered descriptor. The failure cuts off its post-tick native-pose and clock checks; this is not yet a full native trajectory, acceptance on unchanged main, a scene rollback measurement, or a solver error. Orthogonal parent fixtures on the latter tree likewise report 10→11. The root isolates this question from the separate loss of an otherwise representable pure translation under affine shear.
