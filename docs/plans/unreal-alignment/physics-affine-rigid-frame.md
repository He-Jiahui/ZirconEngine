# Project a proper rigid-body orientation without approximating the scene affine matrix

**Problem-only Draft** on `main@e89349ca51b4e9d024c194cd3bdf645bd25b6c37`. No test fixture or production change at opening. This is independent of [#194 affine collider point](https://github.com/He-Jiahui/ZirconEngine/pull/194), [#195 native placement](https://github.com/He-Jiahui/ZirconEngine/pull/195), and [#145 reverse writeback](https://github.com/He-Jiahui/ZirconEngine/pull/145).

1. **Difference and cause.** [Scene World](../../../zircon_runtime/src/scene/world/query.rs#L595-L601) preserves an authoritative local-to-world matrix. Its convenience [TRS projection](../../../zircon_runtime/src/scene/world/derived_state.rs#L860-L866) divides each axis by its length before extracting a quaternion. Inherited shear leaves the normalized axes nonorthogonal. The [physics World producer](../../../zircon_plugins/physics/runtime/src/manager/world_sync.rs#L37-L66) copies that finite rotation to a rigid-body row, although finite does not imply unit length or a valid frame.
2. **Consequence and proof boundary.** In a prior *local* composition of #194–#197, actual positive/mirrored World fixtures gave `q.length_squared()=.97007453`; separate Builtin affine-point rays hit, but the native #195 nonzero-offset guard rejected the rigid body before its pose entered body FFI. This is admission, not missed collision. The new independent original run will exercise the main-branch scene producer without sending a bad quaternion to Jolt; no dependency on those Drafts and no weakening of the native guard.
3. **Actual Unreal comparison.** Local `Engine/Source/Runtime/Engine/Private/Components/SceneComponent.cpp:727–748` composes the parent with `FTransform`, not an authoritative affine matrix. The signed-scale fallback in `Engine/Source/Runtime/Core/Public/Math/TransformVectorized.h:1548–1584` reconstructs TRS and normalizes q; `:627–662` distinguishes finite from normalized. `Engine/Source/Runtime/Engine/Private/PhysicsEngine/BodyInstance.cpp:2768–2793` rejects a bad pose. `Engine/Source/Runtime/PhysicsCore/Private/ChaosEngineInterface.cpp:2541–2567` writes actor X/R and refreshes bounds; `Engine/Source/Runtime/Engine/Private/Components/PrimitiveComponent.cpp:1080–1084` applies scale separately. This is source comparison, not UE execution or its shear semantics as an oracle.
4. **Rust/ECS contract to freeze.** For non-orthogonal but safely invertible affine axes, choose the proper orthogonal polar factor. If determinant is negative, first remove reflection on local **X**, consistent with the existing signed-X compact scale convention. Keep the reflection/stretch in the affine matrix and existing metadata, not in a quaternion. `diag(±2,1,1)·Ry(45°)` therefore exports `Ry(±45°)`; normalizing the approximate legacy q gives a different angle. Orthogonal existing valid poses are unchanged. Physically unrepresentable/degenerate frames must not manufacture a trusted rigid direction. No change to local ECS editing, collider TRS/radius/point, joint data, public DTO or native settings; this is not scaling/shearing native primitive geometry.
5. **Original-first verification.** Freeze real positive and mirrored shear, a 3D mixed shear with analytic angle differing from the authored rotation chain, a thin but invertible hierarchy, and orthogonal/root plus existing controls. Compare real projected body q, all basis axes, original position/compact scale, unchanged collider row, and independent raw-matrix point/authoring. Publish the actual unchanged-production RED before touching the body producer. #194/#145 historical frozen tests require whole-body equality to the old lossy projection; preserve them and distinguish patch compatibility from any future composed runtime/fixture acceptance.
