# Authored glTF tangent fixture: include the authored normal frame

**Draft — problem definition only.** This unchanged runtime test failed during the [#141](https://github.com/He-Jiahui/ZirconEngine/pull/141) baseline. Its input and failure are independent of Mikk-generated tangent handedness.

1. **Difference.** The [positive fixture](../../../zircon_runtime/src/asset/tests/assets/gltf_primitive_fixtures/vertex_channels.rs#L50-L93) declares `POSITION`, `TANGENT` and `COLOR_0`, but no `NORMAL`. It expects the `TANGENT` bytes to survive unchanged. UE generates flat normals when absent and explicitly discards the source tangents (`Engine/Plugins/Interchange/Runtime/Source/Parsers/GLTFCore/Private/GLTFMeshFactory.cpp:539–590`). ZE's current production fallback follows the same broad rule; the disagreement is in the test fixture.
2. **Effect.** The old CPU test reports the fallback tangent instead of its authored array, before checking the color channel. This is not evidence of an authored tangent being lost when its normal basis is present.
3. **Cause and UE evidence.** ZE [recognizes missing normals at glTF read](../../../zircon_runtime/src/asset/importer/ingest/import_gltf.rs#L60-L94), [builds flat corner normals](../../../zircon_runtime/src/asset/importer/ingest/indexed_mesh_projection.rs#L222-L248), and does not pass the source tangent on that fallback path. Unreal marks the same source tangent unusable after synthesizing flat normals. The fixture needs a valid authored normal to test exact channel retention.
4. **Rust approach.** In the existing glTF import harness, give the positive fixture a complete normal accessor and authored tangent directions perpendicular to those normals, including a negative `w`. Retain the same vertex ordering, color values and labelled child assertions. Keep a distinct missing-normal input as a fallback control rather than changing the production decoder to make an invalid positive control pass.
5. **Interface/ECS boundary.** No renderer, ECS, serialized schema, normal-map convention or Prefab change. UE may convert coordinate handedness; the common behavior is preserving a supplied basis only when the needed normal input exists, not the raw packed values.
6. **Concrete ZE change and gate.** Repair only the owned fixture and the corresponding built-in authored/absent tests after further review. The existing red input remains frozen in #141 evidence. No code, schema migration, GPU run or Unreal binary result is included here.
