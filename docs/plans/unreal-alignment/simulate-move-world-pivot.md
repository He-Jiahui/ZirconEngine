# Simulate Move treats an authored local transform as its world-space pivot

**Problem-only Draft; source hypothesis.** Independent of #205 (Edit-world retained Move), #203 (Script) and solver/render fixes. This is the Simulate-in-Editor host path, not ordinary Play input. No tests, native RED, interface change or production patch in this revision.

1. **Observable path.** The [Play gizmo entry](../../../zircon_editor/src/ui/host/play_gizmo.rs#L159-L185) is gated to `PlayKind::Simulate` and the active Play identity [at validation](../../../zircon_editor/src/ui/host/play_gizmo.rs#L555-L589). Selection in that world [does not exclude attached entities](../../../zircon_editor/src/ui/host/editor_host_event_controller/play_hierarchy.rs#L17-L47). The [existing wire query](../../../zircon_runtime_interface/src/world_sync/query.rs#L132-L167) returns the precise **local** `Transform` and Level world-replacement epoch. The host [capture/begin path](../../../zircon_editor/src/ui/host/play_gizmo.rs#L222-L269) uses that same local value for both the Runtime compare-and-set (correct) and world-space screen picking (not equivalent for a child). The [screen overlay](../../../zircon_editor/src/ui/host/play_gizmo/overlay.rs#L78-L96) does the same. Attached entities may display an axis displaced from actual geometry, hit the wrong position, or preview a world displacement transformed by the parent an extra time. Root cases can hide the conflation.
2. **Affine contract and consequence.** For frozen parent `P=[A,b]`, local `t` is at `A*t+b` in the Play Level. A requested world displacement `d` needs `t'=t+A⁻¹*d`, not `t+d`. Simulation preview currently passes the [world-pivot request directly as the V1 target](../../../zircon_editor/src/ui/host/play_gizmo.rs#L346-L379); [Runtime validates and writes it as authored local](../../../zircon_runtime/src/dynamic_api/session/editor_transform.rs#L89-L115). For a `diag(±2,1,4) * Rz(π/4)` parent built from valid Scene hierarchy, a global X request is generally not an X displacement in local frame; applying it as local X can add world Y and even reverse world X. Keep full `P*L`, signed local R/S bits and existing Play ownership. No wrapper-side TRS approximation for the parent and no lookup in the Edit world.
3. **Local Unreal comparison.** `Engine/Source/Editor/UnrealEd/Private/Elements/Actor/ActorElementEditorViewportInteractionCustomization.cpp:136–151` calls `EditorApplyTranslation` using world location and delta; the *additional* primitive `SetWorldLocation(OriginalLocation+DeltaTranslation)` requires Simulate-in-Editor, `GIsPlayInEditorWorld` and a primitive root. `Engine/Source/Runtime/Engine/Private/ActorEditor.cpp:847–859` moves the Actor root using whole `FTransform`; `.../Components/SceneComponent.cpp:1996–2026` uses parent socket-relative TRS. That establishes world intent and Simulate ownership, not an affine oracle, ordinary PIE guarantee or a reason to copy the compact conversion.
4. **Ownership and compatibility to demonstrate.** The production linked and native dynamic Play routes use a serialized `SessionGateway`. Authored local `TransformSnapshot` and V1 local compare-and-set are used for begin/cancel/history and must not silently become world-space. A credible correction needs a coherent per-entity world pivot and parent affine context from the same Runtime world; if the parent/attachment may change during the drag, validation of a stale projection must not depend on matching a cached local value alone. Check existing contracts before adding anything; no V8 C table field/size change, broad reflected-scene polling, or migration proposal in this Draft. Do not conflate Simulate preview with the separate retained command/undo path.
5. **First frozen proof.** Existing Editor host Simulate selection plus actual linked headless Runtime/V8 function table and `SessionGateway` (real frame/preview/cancel and Runtime Scene; no fake result). Measure root control, translated child screen pivot, and positive/reflected sheared attachments with real Move Preview and Cancel, correct world displacement, published ECS matrices and retained exact local R/S. Verify Play-only writes, not user-facing game input. First run unchanged production and publish measured RED before any fix. Full window/render acceptance and simulation history commit are separate; no passed required check is claimed here.
