# Preserve collider placement in the Jolt manager query snapshot

**Problem-only Draft** on `main@e89349ca51b4e9d024c194cd3bdf645bd25b6c37`. No fixture, execution or production change yet. Not [#194](https://github.com/He-Jiahui/ZirconEngine/pull/194) World affine source, [#195](https://github.com/He-Jiahui/ZirconEngine/pull/195) native Jolt shape creation, or reverse body-to-ECS writeback. No dependency on those Drafts.

1. **Difference.** [Jolt manager readback](../../../zircon_plugins/physics/runtime/src/manager/jolt_world.rs#L259-L286) correctly accepts active rigid-body states, then copies each active body's entire transform to its distinct collider. This loses a valid offset, compact orientation, and shape scale even when native motion is zero. Inactive rows are not overwritten.
2. **Consequence to measure.** [Published manager snapshot](../../../zircon_plugins/physics/runtime/src/manager/jolt_world.rs#L335-L347) is read by [the shared CPU ray query](../../../zircon_plugins/physics/runtime/src/manager/query.rs#L18-L57). A native-active body with an offset small sphere can appear to collide at the body origin instead of the collider point. Under actual motion the query center must follow the observed rigid pose delta, not remain at the pre-step absolute world point. This is not the native Jolt look-up or native collision response.
3. **Actual Unreal comparison.** Local `dev/UnrealEngine/Engine/Source/Runtime/Engine/Private/PhysicsEngine/Experimental/PhysScene_Chaos.cpp:2552–2565` consumes the particle pose for component motion. `Engine/Source/Runtime/Experimental/Chaos/Private/Chaos/ShapeInstance.cpp:548–582` combines leaf-relative placement with participant pose, for both direct and cached shape transforms. `Engine/Source/Runtime/Experimental/Chaos/Public/Chaos/Collision/SimSweep.h:148–169` uses a composed leaf transform in its filtered overlap. The existing offset-box manifold test `Engine/Source/Programs/HeadlessChaos/Private/HeadlessChaosTestOneShotManifolds.cpp:105–129` keeps geometry offset and body transform separate. These are source contracts, not executed UE evidence or a shear oracle.
4. **Rust direction after measured RED.** Keep the pre-step body frame and apply the observed rigid delta to the *projected collider* point and compact orientation. Preserve compact scale rather than deriving it from the native body pose. Do not invert/decompose the whole scene hierarchy or substitute UE FTransform for `WorldMatrix`. Matrix authoring and signed/sheared primitive policies remain at their respective owners.
5. **Interface/ECS.** `PhysicsWorldSyncState` already exposes separate body and collider transforms. Preserve both and their world/identity/cache metadata, rather than reading mutable ECS in the query lane or changing ABI. No native shape, event, runtime collider recreation, or queued teleport change. A queued teleport currently erases placement earlier and is deliberately excluded here.
6. **Test first.** Extend the [existing Jolt manager tests](../../../zircon_plugins/physics/runtime/src/manager/tests/jolt_world.rs) with actual World synchronization, an admitted linked native QueryOnly case and a real nonzero step under a rigid parent, plus inactive, coincident and existing constraint controls. Compare real hit/miss/position/normal against an independent body-frame expected point and old absolute point; confirm native state presence before interpreting any empty query. Windows/MSVC Rust test / upstream Jolt C++ Release; leaf physics libtest only, no render/GPU claim for this CPU query. Freeze the cases and publish original behavioral RED before changing production.
