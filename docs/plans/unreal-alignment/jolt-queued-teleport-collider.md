# Preserve Jolt collider placement when preparing a queued rigid teleport

**Draft — measured original command RED** on `main@e89349ca51b4e9d024c194cd3bdf645bd25b6c37`. Frozen fixture executed; production unchanged. Independent of [#196 active readback](https://github.com/He-Jiahui/ZirconEngine/pull/196), [#195 native shape creation](https://github.com/He-Jiahui/ZirconEngine/pull/195), and [#194 affine World collider point](https://github.com/He-Jiahui/ZirconEngine/pull/194).

1. **Difference and cause.** [Jolt command preparation](../../../zircon_plugins/physics/runtime/src/manager/command_buffer.rs#L194-L228) takes separate body and collider sync rows and assigns the queued `Teleport` transform to both, **before** [native synchronization](../../../zircon_plugins/physics/runtime/src/manager/jolt_world.rs#L56-L100). The requested body pose is valid; the distinct collider position, compact rotation and scale are lost. Static bodies do not enter active readback, so this has a separately testable failure even without #196.
2. **Consequence to measure.** The [shared manager CPU ray query](../../../zircon_plugins/physics/runtime/src/manager/query.rs#L18-L57) can hit an incorrect sphere at the requested body origin while missing the intended offset sphere in the published snapshot. The old absolute center must also miss after a real queued move. Compare a translation-only move and a move with a yaw. This is not a native Jolt scene query or collision response claim.
3. **Actual local Unreal.** `Engine/Source/Runtime/Engine/Private/PhysicsEngine/BodyInstance.cpp:2787–2839` chooses the actor pose or kinematic target. `Engine/Source/Runtime/PhysicsCore/Private/ChaosEngineInterface.cpp:2541–2567` sets particle X/R, updates shape bounds and the acceleration structure; kinematic teleport clears V/W. `Engine/Source/Runtime/Experimental/Chaos/Public/Chaos/ParticleHandle.h:2882–2896` passes the body pose to each shape's bound calculation. `Engine/Source/Runtime/Experimental/Chaos/Private/Chaos/ShapeInstance.cpp:423–432,548–582` keeps distinct shape geometry and the composed leaf pose. `Engine/Source/Programs/HeadlessChaos/Private/HeadlessChaosTestPhysicsScene.cpp:174–226` actually queries old/new locations across SetGlobalPose, using a **centered** shape. These are local source references, not executed UE or evidence for inheriting its affine limitations.
4. **Rust/ECS plan after measured RED only.** Keep the target body assignment and the command boundary. For a supported same-scale rigid teleport, move the **existing collider row** from the command's input frame to the target rigid frame, preserving its projected scale. Do not reinterpret that metadata as native body scale or invert/decompose the scene affine chain; changed body scale and unsupported/invalid frames are separate policy questions. World local authoring, ECS layout, command admission, native shape/event storage and backend setters remain untouched.
5. **Freeze evidence first.** Extend the existing Jolt manager test suite with a separate test-only submodule. Use an actual World, static native body existence and no native active row, `Simulate` zero-step baseline, accepted queue and positive-step drain. Compare published point/orientation/scale, actual shared rays at correct/target-origin/old centers, and source ECS untouched. Keep no-command, coincident, changed-scale legacy and existing joint controls. Source inspection is not RED. Publish the frozen old-production result before touching the command owner.
