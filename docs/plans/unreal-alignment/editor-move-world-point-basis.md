# Editor Move preview should not re-author local rotation and scale

**Problem-only Draft.** This is a source/analytic hypothesis on `main@e89349ca51b4e9d024c194cd3bdf645bd25b6c37`. No executable RED or fix yet. It is independent of Script #203, viewport affine extraction #144, the Play gizmo, or solver pose writeback.

1. **Difference.** [The Move handle](../../../zircon_editor/src/scene/viewport/handles/move_handle_tool_behavior.rs#L65-L95) changes only the world pivot position. The [retained session](../../../zircon_editor/src/core/editing/interactive_transform/session.rs#L65-L109) freezes each selected root's `NodeEditState`, full world matrix, and checked parent inverse. [Preview](../../../zircon_editor/src/core/editing/interactive_transform/session.rs#L242-L307) nevertheless applies and decomposes a full target matrix for every tool, including Move.
2. **Expected symptom.** An exact unchanged pivot for authored root `q=I,s=(-2,-3,+0.5)` can produce the same world matrix, yet decompose to `q=Rz(π),s=(+2,+3,+0.5)`. A moved signed child under shear can similarly land at the correct point while re-authoring unrelated fields. [Finish](../../../zircon_editor/src/core/editing/interactive_transform/session.rs#L309-L337) builds a retained command when the authored Transform differs. The [Workbench release](../../../zircon_editor/src/ui/workbench/state/editor_state_viewport.rs#L241-L263) then commits it as a history transaction, so an unchanged-point preview may create an undo entry. This is a prediction about explicit preview/release, not a claim that a mere press/release always previews or that the first frame's geometry is wrong.
3. **Actual local Unreal reference.** In the supplied `dev/UnrealEngine`, `Engine/Source/Editor/UnrealEd/Private/EditorEngine.cpp:3276–3299` delegates editor deltas to typed-element adapters. `.../Elements/Component/ComponentElementEditorViewportInteractionCustomization.cpp:223–258` applies component translation via `SetRelativeLocation`, separately from scale. `.../Elements/Actor/ActorElementEditorViewportInteractionCustomization.cpp:433–458` applies actor delta/absolute translation via `EditorApplyTranslation` / `SetActorLocation`. `Engine/Source/Runtime/Engine/Private/ActorEditor.cpp:847–859` actually changes the translation of a compact `FTransform` and calls `SetWorldTransform`; therefore this is not an Unreal local-R/S, general affine or undo-count oracle. `Engine/Source/Editor/Experimental/EditorInteractiveToolsFramework/Private/EditorGizmos/EditorTransformProxy.cpp:58–75` sends translation with separate zero rotation/scale deltas, and `Engine/Source/Editor/UnrealEd/Private/LevelEditorViewport.cpp:4263–4266,5663–5677` checks input/external-movement flags to end or cancel tracking, not equality of ZE authoring records. Neither relative-unit behavior, UE's compact transform, nor its transaction heuristic should be transplanted to ZE.
4. **Potential narrow approach.** For typed Move, compute the requested world pivot displacement `d`, advance each frozen full-matrix origin by `d`, then pull that point back with the same full parent affine inverse. Keep before-state local R/S; when `d=0`, restoring the exact frozen local transform avoids numeric drift and fake history after a return to the start. Preserve target/document/parent validation and prepare the whole selected root batch before touching the Scene. Rotate/Scale keep the existing checked nonrepresentable-pose refusal.
5. **Ownership/interface.** The editor owns Move intent, selected roots and retention/undo; Scene owns authored `LocalTransform` and derived `WorldMatrix=parent_world*local_matrix`. Keep public viewport request shapes, transaction/journal schema, undo/redo application, hierarchy, prefab, world transform publishing, and renderer unchanged. Do not mix with #203 or #144.
6. **Frozen proof to obtain.** Verify signed exact no-op (same point, no world revision or actual retained history record), a drag out and back with no final history record, and a move under genuine positive/reflected parent shear (including multi-root alignment, real commit/undo/redo and published matrix, not a synthetic renderer read). Keep existing normal move, rotation/scale, stale/static and transaction controls. Measure unchanged-main CPU first, then exact rerun after the narrow owner change. This scope uses an in-process Editor transaction test, not a real GUI or product gate claim.
