- Date: 2026-08-21

## Scope

- Remove the blanket `unsafe impl<T> Sync` from `NativePluginStatic<T>`.
- Restrict static synchronization to the five immutable ABI carrier types generated by the SDK and fixed-size arrays of those carriers.
- Keep the public transparent wrapper, constructor, shared accessor, and raw const pointer API unchanged.

## Safety Contract

- The private unsafe marker is implemented only inside the SDK, so downstream crates cannot add an unaudited carrier.
- `NativePluginStatic<Cell<_>>` and other interior-mutable values no longer satisfy the `Sync` requirement for a Rust `static`.
- Descriptor, behavior, entry-report, bridge-table, and bridge-method carriers remain valid generated statics.
- Raw carrier pointers are immutable ABI data; pointee and callback synchronization remains owned by their respective contracts.

## Performance Evidence

- `NativePluginStatic<NativePluginEntryReportV3>` retains exactly the payload size and alignment under `repr(transparent)`.
- `as_ptr()` and `get()` address the same carrier, with zero layout overhead bytes, zero runtime guard branches, and zero runtime allocations.
- The validation marker is `PERF-MVP-PLUGINS01-SEALED-NATIVE-STATIC`; this safety hard cut introduces no timed hot-path work.
