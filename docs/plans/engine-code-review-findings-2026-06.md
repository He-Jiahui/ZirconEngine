- **生产代码无 `TODO`/`FIXME`/`HACK` 注释**（zircon_runtime/src、zircon_editor/src 零命中）——债务藏在结构里而非注释，印证本目录"结构债优先"取向。
- **`ui/v2` 的 `expect` 多为带说明的合理不变式**（`file_cache.rs:408`、`loader.rs:81`、`style.rs:103`），非应返 Result 的误用。
- **editor/app 直接依赖 winit + softbuffer 是有意设计**（拥有原生窗口/事件循环），无 wgpu/slint 泄漏；建议规范明确"editor/app 允许 winit+softbuffer、禁 wgpu/slint"消除"authoring-only"标签歧义。证据：`zircon_editor/Cargo.toml:19,23`、`zircon_app/Cargo.toml:85-86`。

## 5. 优先级建议

最高优先两项是安全/崩溃类：**F1（native 回调缺 catch_unwind，UB）** 与 **F2（scene 每帧 lock().unwrap，poison 崩溃）**；性能侧 **F3（每帧整帧 clone）** 是 ~10fps 头号嫌疑。DX 侧 ROI 最高的是 **D-S7（plugin.toml 死副本→生成）** 与 **D-S8（native 零 SDK）**，应在 Plugins 12 M1/M2 优先落地。
