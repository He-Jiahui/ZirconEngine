## 复用现有模型的接口

`TimelineModel` 已有 `TrackId/Delta/Error`、`descriptor/track_catalog/range/playhead/tracks/apply(delta)->inverse`；`CurveModel` 已有 `CurveId/Delta/Error`、curve views 和可逆 apply。它们不持有具体资产，恰好可承载多域适配。外层 document adapter 仍须提供 source/revision、capability、事务及保存权威；这些不会由 painter 或模型的 view 自动生成。

下表命名是待集成的字段语义，不声称已新增同名 Rust struct 或 ZUI prop。

| 输入/反馈 | 最小字段和语义 | 持有者 |
| --- | --- | --- |
| 文档身份 | project activation、document/source UUID 或 locator、source revision、session generation、只读及诊断 | 域 document；共享控件只核对，不分配资产身份 |

## 意图、反馈与历史

共享层产生意图，域 adapter 验证并提交实际命令；请求附 source revision、session generation、interaction/request ID，回读必须匹配。旧项目/旧资产/关闭前的异步回执不能更新新文档。

| 操作 | 共享意图/反馈 | 域权威和历史边界 |
| --- | --- | --- |
| seek/scrub | begin → update(position) → commit/cancel；同一时间变换命中；显示真实已确认位置和 pending | 默认 transient preview，不每帧产生 undo；是否触发 notify/event 由域显式策略决定，不能把普通拖尺当 runtime tick |
| key/section/tangent 编辑 | begin → update(typed delta) → commit/cancel；稳定 selection 与 source revision | 域校验/重新求值，复用 inverse-delta；一个拖动形成一次原子历史。失败/cancel恢复开始值；不得直接写 runtime源或每次 pointermove 生成历史 |
| 数值输入 | 文本局部编辑，Enter提交，Escape取消；IME composition 中不提交/拦截 | 解析/范围/插值合法性由域决定；成功后更新一次历史；无效果提交不制造 dirty |
| 选择/框选/滚动/zoom/fit | typed element 命中；key/in/out tangent 分开；view只影响本编辑器 | 不产生资产历史；删除/复制/粘贴等通过域支持的命令，paste先验证资产/值类型 |
| Play/Pause/Stop/Loop/Rate | 发送有 capability 的命令；真实状态确认后才显示 playing/loop/rate | 具体后端 clock/output/PIE/session 权威；排队 ACK 不等于开始播放，失败保留诊断；域决定 stop/reset/restore |
| Step/Start/End/Reverse/Record | 各自命令，不由图标推断；按单位和后端能力提供 | 秒、帧、采样、BT trace 步进不同；缺后端或capture时保持不可用及原因，不制造假动作 |

Escape、capture lost、文档切换、关闭或 revision invalidation 结束当前 gesture。焦点局部路由；文本框优先保留剪贴板/撤销/IME，菜单/弹层关闭后回到原 opener 或有效 canvas。域 close/save/dirty 决策复用现有 host。共享层不注册抢占所有文档的 Space/Delete/Ctrl+Z。

### 消费者拒绝、异步完成与帧关联

现有`TimelineModel/CurveModel.apply`的同步inverse-delta适用于文档编辑，不等同于preview seek或job完成。下面是通用adapter的待接语义，具体DTO须由consumer/Parent复用已有中性能力确定，本轮没有新增Rust返回类型、事件或props。

| 阶段/结果 | 共享表面必须表达的语义 | consumer权威 |
| --- | --- | --- |
| 提交前/拒绝 | available仅是当前提示；提交可因不支持的单位/倍率、未就绪、只读、过期source或预算而被拒绝。保留最后确认位置/值，显示真实reason | 域再次校验source/session/owner generation、handle、范围和实际执行条件；拒绝不产生source dirty或虚假播放变化 |
| 同步完成/异步受理 | 已完成须有实际执行确认；仅受理则为pending并关联request/job。可显示明确标注的requested target，不能将其覆盖成已确认playhead | 域声明支持同步、异步及取消的范围；现有同步阻塞函数不能仅被UI包装成“异步有界” |
| 完成回读 | 同时保留requested time/单位与actual applied time/单位，clock权威、执行序列和倍率语义；不能假设二者相等。旧request的完成不得覆盖较新请求或新source | consumer提供实际执行结果；排队ACK、预计耗时、UI wall-clock与GPU计数都不是applied time |
| 帧/资源就绪 | 区分simulation已应用、render准备/资源ready、有效frame发布及实际呈现。反馈关联document/source、preview owner/session/handle generation、request/clock序列、frame/publication及真实backend | consumer负责runtime与source关联，Parent衔接生产viewport。帧较旧或last-good需显式标记，不把其它owner/主场景帧当当前preview |
| 失败/取消/退休 | 失败保留诊断；取消请求不等于已取消；超时不等于终态。source切换/关闭退休结果关联，实际job/资源仍需结束和释放 | 有能力才执行取消；无法取消应明确仍在运行/隔离处理，不用清pending标签冒充停止。旧结果在执行/发布前和消费时核对，不能只丢UI通知 |

只有真实执行确认后才更新confirmed position；只有匹配的资源/帧证据才升级对应ready/present状态。相同job的重复回执、乱序完成、切文档、重建owner及最后消费者关闭必须有确定策略。共享控件不实现scheduler、模拟器或第二个clock；文档gesture的取消和运行job的取消分别确认。

### 单一时钟、播放与焦点接口

时间快照由Widget所选的**真实预览采样权威**发布，timeline ruler/lanes、curve cursor和transport读同一position/view range。共享组件不创建第二个ticker。快照至少要能核对文档/动画/source revision/session generation、权威身份、有限position和有效范围/单位、播放状态/rate/loop、逐操作capability、最后确认request及错误；这是外层adapter待定输入，不是`PreviewPlayback`现有字段。FPS仅是域声明的显示/吸附信息；不得假定30FPS或用设计空态0–1秒当Widget时长。

| 操作语义 | 共享表面发送与回读 | Widget/宿主责任和未决项 |
| --- | --- | --- |
| scrub/seek | begin保存起点；update发送有限目标时间及interaction/request序列；只将匹配的确认显示为已应用；commit结束手势、cancel恢复起点 | 域确定clamp/loop边界、拖动时是否暂停及释放恢复策略、是否触发事件；无能力不假移真实playhead。旧请求不得晚到覆盖较新时间；scrub不改持久源 |
| play/pause | Play/暂停发送独立意图，展示pending/playing/paused或失败 | 单一真实clock推进；Pause保持已确认位置/值。排队成功不是已开始播放；source/session切换先终止或迁移旧播放，策略由Widget确认 |
| stop/reset | Stop为独立命令，返回停止后时间、属性处理结果及实际实例代际 | 必须明确停在当前、回区间起点、恢复采样前值或重建实例的策略，以及失败恢复；不得把Pause称Stop或擅自采用3D预览行为。Reset是否重建现有Surface也由Widget明确 |

### owner 寿命、操作与失效

一个preview owner只持一个活动`ParticlesManager`、一条clock和render consumer；Dock Preview与独立Preview tab是同一owner的消费者。切tab不新建模拟、不各自tick，关闭一个消费者不误停仍被使用的owner；最后消费者关闭的任务/帧/资源释放由粒子与Parent生命周期合同确认，不操作主场景manager或借主场景画面。

### RT-S09 SoundWave 秒/采样与真实输出
