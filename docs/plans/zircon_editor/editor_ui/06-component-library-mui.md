# 06 MUI 式组件库落地

## 1. 目标

按 MUI 的自底向上组件分类，把编辑器需要的全部组件做成「runtime 路径完整」的真实组件：每个组件 = `.zui` 资产 + component descriptor + 语义状态机（state reducer）+ Taffy 布局描述 + selector 化样式 + render extract + 输入行为 + 焦点/可访问性语义。组件是统一描述、可拼装的——多个相似布局一种声明，禁止逐组件像素特调。

## 2. 现状（按代码核实修正）

### 2.1 已存在的设施

|------|------|------|
| 组件契约 | `zircon_runtime_interface/src/ui/component/` | `UiComponentFlags`（state.rs:9）、`UiComponentState`（state.rs:25）、`UiComponentEventKind/UiComponentEvent`（event.rs:7/:43）、descriptor/、data_binding/、drag.rs、catalog/、category.rs、validation.rs |
| catalog | `zircon_runtime/src/ui/component/catalog/material_foundation/` | 25 个子模块文件：inputs、button_inputs、selection_inputs、text_inputs、form_controls、data_display（+editor/subcomponents/table）、feedback、layout（+editor/mui/transitions/utilities）、navigation（+editor/secondary/subcomponents）、surfaces、surface_subcomponents、mui_x、lab_subcomponents、shared |

### 2.2 真实缺口

1. 「covered」≠「行为完整」：现有原语多数有渲染与基本点击，但键盘交互、焦点语义、编辑行为、popup 行为完整度参差，且无逐组件的 7 维盘点记录。
2. `.zui` 缺口（对照 §3 清单）：L1 的 Label、Icon、ProgressBar、Divider、Skeleton、NumberField、SearchInput、RangeSlider、TabStrip 独立 Workbench 资产已补齐并纳入 32 项治理脚本；这些组件的行为、状态矩阵、render 对拍仍未到完整 DoD。L3 仍缺 ContextMenu、DropdownPopup、Alert、Dialog/ConfirmDialog、CommandPalette、NotificationCenter、DragOverlay。
3. `state_reducer` 是单入口函数，组件 family 行为未分表；部分行为仍在 editor pointer bridge / template bindings（依赖计划 01 M5 收编）。
4. 复杂组件（Dropdown 弹出定位与完整 popup focus-loop、Slider 状态矩阵、TextField 计划 03 全编辑链、TreeView 虚拟化+展开+多选、Table 列宽/排序、PopupMenu 多级）未定稿；其中 TextInput 已有 printable `KeyboardText` 插入桥接、默认 append、显式 selection 替换与 caret 写回基线，SearchField/Autocomplete 已有 query-backed 宿主文本编辑属性路由，MUI TextField 已有 Delete/ArrowLeft/End、active-selection Backspace、Ctrl+Backspace 词删除、Ctrl+A 全选替换、Shift/Ctrl+Shift 选区扩展、Textarea ArrowUp/ArrowDown/Home/End/Enter retained edit-state 宿主物理键覆盖，并新增 IME preedit/commit/cancel retained composition 用例；窗口适配器已将 ABI `ime_disabled` 映射为 UI `Cancel`，retained IME context 已能在 `wrap`/`multiline` 节点上按 soft-wrap 行拆分 cursor/composition rect，TextField render extract 已能把 composition metadata 注入 `UiResolvedTextLayout` preedit span，TextInput reducer 已覆盖 `validation_timing = change|commit|blur`、dirty/touched 标记与 required/min/max-length 校验。RangeSlider 已有 lower/upper 键盘目标、value/percent mirror、最近 thumb 轨道点击/capture 分发、drag-session 属性锁定、默认 lower/upper 交叉夹取和 `disable_swap=false`/`disableSwap=false` active-thumb swap 策略。Menu/MenuList 已有跨 `KeyboardText` 事件 retained typeahead buffer、`TypeaheadExpired` 语义事件、过期重置入口与宿主 tick 计时派发，但不等同于完整文本编辑器或完整 popup/menu 行为。

## 4. 关键行为定稿（挑大头）

- **Dropdown/PopupMenu**：anchor 定位 + 屏幕边界翻转/夹取（Overlay 容器）、外点关闭、Escape 关闭、方向键/Home/End/输入首字母导航、retained typeahead buffer、`TypeaheadExpired` 过期语义与宿主计时派发、多级子菜单 hover 展开延时（01 timers）。
- **TextField**：先承接 M1.S4 printable `KeyboardText` 插入桥接，覆盖无状态默认 append、显式 selection 替换与 caret/selection 写回，让 query-backed `SearchField`/`Autocomplete` 的宿主编辑路由写回 `query`，并用 MUI `TextField`/`TextareaAutosize` focused host route 验证 Delete、ArrowLeft、End、active-selection Backspace、Ctrl+Backspace、Ctrl+A 替换、Shift/Ctrl+Shift 选区扩展、ArrowUp/ArrowDown/Home/End/Enter 会更新 retained edit-state；指针路径已覆盖 hit-test、拖拽选区、双击选词与三击选行；IME 路径已覆盖 ABI disabled -> UI Cancel、MUI TextField preedit 选区替换、commit 原子提交与 cancel 恢复组合前文本、retained IME context 的 soft-wrap cursor/composition rect 拆分，以及 TextField render extract 的 `UiResolvedTextLayout` preedit span 注入；验证路径已覆盖 `validation_timing = change|commit|blur`、dirty/touched 标记与 required/min/max-length 校验；完整计划 03 编辑链仍包括平台候选窗实机定位与实机中文输入；NumberField 附加拖拽改值、步进、min/max/精度、表达式留接口。
- **TreeView**：虚拟化（02 M3）、展开状态、单/多选（Ctrl/Shift）、键盘展开折叠、行内重命名、拖拽重排（reply drag）。
- **TableView**：列定义、列宽拖拽、排序指示、行选择、虚拟化滚动。
- **Slider**：轨道点击跳值、拖拽 capture、键盘步进、双滑块范围；RangeSlider 键盘路径已能按 `focused_thumb = lower|upper` 分别写 `range_min` 或 `value`，并保持双 thumb 夹取；`state_reducer/slider.rs` 已补 `value`/`range_min` 与 `value_percent`/`range_min_percent` 双向同步；默认 pointer press/move/release 已通过 `RangeSlider -> Range` widget 推断按点击值选择最近 lower/upper thumb，drag session 锁定该属性，并在 `disable_swap = true` 默认策略下把 lower/upper 交叉夹取到 `range_min <= value`；`disable_swap = false`/`disableSwap = false` 时按 MUI `disableSwap=false` 语义交换 active thumb、同步写两个端点。后续仍需 selector 矩阵和更大 runtime lib-test 覆盖。
- **Tooltip/Toast**：input manager 计时（01 M3）、Toast 队列与超时归 runtime 组件状态。

## 12. 边界约束

- 组件行为状态机归 runtime state reducer；editor 只接收语义事件（route id），不实现组件行为。
- 不追求 MUI 全集（DatePicker/Charts 等 mui_x 高级件按需后置）；以编辑器设计图实际用到的集合为版图。
- L4 表面资产在 `zircon_editor/assets`，但其实现不得内联重复 L1–L3 结构（治理测试把关）。
- L2 容器类不造 `.zui` 壳——容器即 `UiLayoutStyle` 声明 + descriptor 注册，避免无意义资产文件。
