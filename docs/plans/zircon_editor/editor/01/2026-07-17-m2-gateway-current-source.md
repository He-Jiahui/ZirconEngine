## 架构边界

- 借用式 world 访问只属于同进程实现；detached/session-backed 实现必须通过序列化合同，不增加兼容旁路。
- `EditorRuntimeGatewayHandle` 是消费者持有的稳定门面；UI 不应缓存 gateway 内部的 `LevelSystem` 或 `World`。
- 借用回调是持 world mutex 的叶节点：回调内再次进入任一 gateway 借用 API 会得到 `ReentrantBorrowedWorldAccess`，不得等待自锁；panic 后 RAII 恢复访问状态。
- 回调内只做有界读取或原子编辑，不执行资产 IO、全量投影或等待任务，避免把 UI/渲染帧阻塞在 world mutex 上。
- 当前操作 API 的 capability-missing 行为保持不变。本切片没有伪造 operation/session 能力，也没有新增旧架构兼容层。
- `RuntimeSession` 是 create/destroy 的唯一生命周期 owner；`SessionGateway` 只接收调用所需的 normalized entries。当前源码已删除 normalized table 的 lifecycle pointers，最终 current-source 复审为 0/0/0；lifecycle 1/1 与 gateway matrix 24/24 已受管 GREEN，app runtime-library 上行门仍 pending。
