## 已确认的关键契约

命中记录拥有目标身份、命中数据及策略的副本。构造器只建立值，不查询场景、不验证实体仍然存在，也不延长实体或相机的生命周期。修改后续记录不会改写已有悬停快照或事件中的历史数据；消费者仍须在实际使用实体时处理有效性。

目标身份的全值相等关系包含目标类别、拥有者及必要的轴信息。同一实体的正文、相机、编辑器叠层与不同操纵轴可以是不同目标。类别优先级参与完整命中排序；目标的派生顺序还比较其他身份字段，不能替代包含后端顺序、深度与来源位置的命中排序契约。

遮挡与悬停策略相互独立。实际投影按已排序命中处理：可悬停的遮挡目标先进入结果再终止，不可悬停的遮挡目标终止处理而不进入结果。手工构造悬停快照的入口不会重新执行排序或遮挡截断。

命中数据的含义由生产后端提供。几何后端与编辑器屏幕评分路径使用不同的数据来源；记录和目标构造器不建立统一的距离、位置或法线有效性保证。文档引用实际生产与消费契约，不把构造函数名称当作额外验证。
