# 24：公共输入契约与运行时管理器文档

## 范围和状态

本阶段为公共输入接口、快照、帧快照、事件、事件记录与按钮六个文件，以及默认输入管理器、输入状态、输入驱动与运行时挂载四个文件补齐中文文档。说明覆盖摘要、职责、使用时机、适用参数、返回语义、必要约束、数据所有权与生命周期边界、参考接口；字段和枚举成员按其实际语义说明，不虚构参数或返回值。

十个文件新增一百五十八段共一千八百二十七行，逐项审查覆盖三百七十一个对象。主审与独立 agent 已完成当前内容和原候选复核。程序行为、公共 API、原程序字节和既有注释均保留。正式覆盖账本发布、Jenkins 阶段提交及全仓扫描仍未完成。

## 审查与验证

主审沿 trait 默认方法、具体实现、描述符与服务工厂、解析句柄、调用守卫、事件队列、录制回放入口及测试读取调用上下文。接口默认无操作与具体管理器的状态访问分别说明；录制回放区分开启下一帧与向既有帧追加事件。驱动文档明确服务描述符保存工厂、句柄不持有实例、进入调用取得守卫及释放调用额度的边界。

十份文件按实际继承的 Cargo edition 2021 通过 stdin `rustfmt`，对应 scoped `git diff --check` 通过。内存中移除本批新增片段，均恢复精确起始哈希；混合行尾文件仅用内存规范化进行格式比较，源行尾保持原样。未运行 Cargo、Rustdoc 或动态测试。

独立 agent 复核六份公共契约的全部一百零八段增量、引用定义与重导出，以及核心四文件的全部五十段增量、四十九份冻结候选与主审修订。核心原候选包仍为 `PREPARED_UNSEALED`，旧 host closeout 回执缺口保持开放；本阶段的字节、语义和格式证据不替代该回执或业务采用。

## 证据与交付

逐项对象、精确增量、最终哈希、引用绑定、原候选来源、主审修订与失败恢复记录保存在既有任务输入 `E:/cargo-targets/zircon-local/reports/source-audit-20260930-01a0f168/artifacts.json` 的 `public_input_service_comment_increment_r1` 与 `runtime_input_manager_core_comment_increment_r1` 条目。原始候选、原有注释作者与历史证据保留；当前审查不表示整份文件业务采用。
