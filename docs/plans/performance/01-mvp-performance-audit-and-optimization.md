# MVP 性能审查与优化 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `continuous-milestone-execution` and `zircon-dev-validation` to execute this plan milestone-by-milestone. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 逐个验收仓库 Rust 文件，先证明并优化 F0-F5 最小可运行引擎与基本编辑器路径的启动、帧循环、调度、内存、I/O、编辑器交互和最小渲染性能，再把非 MVP 与插件问题路由给现有责任计划。

**Architecture:** 使用“产品路径动态基线 + 逐目录逐文件静态审查 + 现有 profiling 埋点 + CPU/线程/内存/GPU 工具”四层证据。`pending.md` 是唯一待验收清单；一个模块只有在其范围内每个 `.rs` 文件均被阅读、风险扫描和相应测试/实测覆盖后，才按模块文件夹整体移入 `review.md`。发现由既有编号计划拥有的问题时，本计划记录症状与证据，并把修复项回填到责任计划；简单且低风险的问题可在取得文件租约后直接修复。

**Tech Stack:** Rust/Cargo、Zircon profiling (`profile_scope!`、Chrome/Tracy/memory features)、Windows Performance Recorder/Analyzer、xperf、RenderDoc CLI（安装可用后）、wgpu markers/timestamps、PowerShell 静态审计、仓库 Windows 验证器。

## 设计决策

推荐并采用 **MVP 产品路径优先**：先对 F0 启动/退出、F2 场景帧循环/输入/最小渲染、F4 编辑器打开/选择/修改/保存建立可重复基线，再扩展资产、插件和非 MVP 系统。

未采用的路线：

- 仅做全仓静态扫描：能够快速找出 `clone`、排序、锁和线程创建，但不能判断真实频率、帧预算占比或 GPU 成本。
- 先平均覆盖 17,706 个 Rust 文件：形式覆盖较快，但会让声音、高级渲染、AI、网络等非 MVP 模块挤占 F0-F5 验证资源。

## 验收定义

模块进入 `review.md` 前必须同时满足：

1. 该模块目录下每个 `.rs` 文件已逐个阅读，入口、数据流、循环、分配、锁、I/O、线程与触发频率已核对。
2. 已运行针对该目录的静态风险扫描，至少检查重复克隆/收集、循环内分配或排序、线性查找、阻塞锁/I/O、裸线程、无界通道、忙等、每帧重建和高频日志。
3. 已阅读对应测试、MVP 计划和直接调用方；动态可达模块必须至少有一次产品/基准/聚焦测试证据。
4. 动态证据记录运行配置、重复次数、样本窗口、CPU/线程/内存或 GPU 指标；单次 wall-clock 不作为优化结论。
5. 问题已修复、移交责任计划，或明确记录为可接受风险；不能只写“看过”。

## 基线指标与预算

| 路径 | 必测指标 | 首轮判定方式 |
|---|---|---|
| F0 runtime/editor 启动与退出 | wall-clock、CPU time、峰值工作集、线程峰值、I/O bytes、阻塞/等待、两次连续启动差异 | 先记录当前源事实；相同配置至少 3 次，报告中位数和极差 |
| F2 帧循环 | CPU frame p50/p95/p99、主线程最长 scope、worker 利用率、队列深度、分配/上传、draw/pass 数 | 16.67 ms（60 Hz）作为观察线；无证据前不设硬回归阈值 |
| F2 最小渲染 | CPU submit、GPU pass timing、draw/dispatch/copy、barrier、pipeline miss、upload bytes | RenderDoc + wgpu timestamp/marker；产品一致性先于降质 |
| F4 编辑器 | 启动、idle CPU、交互 p95、recompute/paint、消息 drain、job queue、预览/资产刷新 | 空闲 30 s 与操作脚本窗口分别采样，区分 idle 与 burst |
| 插件 | 加载/发现/注册/卸载、回调频率、后台任务、每帧插件成本 | MVP 必需插件先测；非 MVP 只在产品路径可达时占验证 lane |

基线冻结后，每个责任计划必须给出本模块的绝对预算或相对回归阈值；计时噪声较大的 CI 只存工件，不直接设脆弱 wall-clock 门禁。
