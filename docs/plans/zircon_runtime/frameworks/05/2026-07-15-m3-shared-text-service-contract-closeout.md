## 范围

本记录只归档 Frameworks05 M3 S1。目标是把共享文本请求、结果、度量、render mode 与服务 trait 硬切到 `core/framework/text`，把 shaping、layout、font、atlas 等实现硬移到 runtime `text` 域，并将 UI 与 graphics 同时改成普通消费方。不得保留 `framework::render::text` re-export、`graphics::text` 转发模块或路径 alias。

## 已批准架构

- 契约 owner：`zircon_runtime::core::framework::text`，按 M1 签名基线提供 `TextShapeRequest`、`TextShapeResult`、`TextLayoutMetrics`、`TextRenderMode` 与 `TextLayoutService`；契约不得引用 `ui`、`graphics`、wgpu、fontdb 或具体字体数据库。

- 消费边界：UI 和 graphics 只依赖 `framework::text` DTO/trait 及 runtime text 服务入口；两者之间的文本路径引用必须双向归零。
