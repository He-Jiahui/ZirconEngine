## Scope delivered

- Added scene/project authoring for global volumetric-fog settings and per-light volumetric participation, including serde-default compatibility and project-asset round trips.
- Extracted local fog media from `PostProcessVolumeComponent + ColliderComponent`, preserved render-layer masks, and filtered local media against the active camera mask before GPU upload.
- Separated post-process `volume_mask` from volumetric-media `culling_mask`: local fog follows the union of the selected base camera and referenced overlay camera render layers, while ordinary post-process overrides continue to follow volume layers. Each camera executor still applies its own final layer filter. Local volumetric profiles no longer enter the global VolumeEvaluator, and degenerate/non-finite fog bounds are rejected before upload.
- Extended `AdvancedLightingExtract` with deterministic volumetric-light IDs and packed participation into `GpuLightData.cookie_misc.z`; light-scatter WGSL rejects lights that do not participate.
- Added the `VOLUMETRIC_FOG` shader feature bit, pipeline-key propagation, and pass-specialized enabled/disabled sources for forward, deferred, and sky pipelines.
- Corrected the shared shadow scene bind group to bind default SH9 data at binding 6, matching the seven-entry environment scene layout used by real WGPU product execution.
- Reconciled the volumetric product fixture with `ProjectAssetManagerAccess` and corrected the Shader IDE dependency expectation now that volumetric code is pass-specialized.
- Replaced absolute-fragment-coordinate transmission sampling with viewport-local UV reconstructed from `scene.view_proj * world_position`; added Naga validation for forward and sky feature-enabled/disabled variants.
