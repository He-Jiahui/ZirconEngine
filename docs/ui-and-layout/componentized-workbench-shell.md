# Componentized Workbench Shell

`docs/ui-and-layout/workbench.png` is a design-density baseline, not a runtime UI layer. The active editor workbench must be built from declared UI nodes so layout, input, render extraction, and command-stream replay remain inspectable and replaceable.

## Ownership Split

- `zircon_runtime` owns neutral UI foundations: Taffy-backed layout selection, input dispatch, render extraction, and the wgpu screen-space UI pass.
- `zircon_editor` owns authoring structure: workbench shell composition, editor-specific tokens, tool-window arrangement, and command routes.
- `zircon_app` continues to translate platform events into runtime/editor input contracts.
