# Review Animations

Review the requested motion scope using [the shared standards](STANDARDS.md). Confirm findings with current code and, when the claim depends on perception or performance, relevant visual or runtime evidence.

- Check purpose and interaction frequency, duration/easing, origin, interruption, performance, reduced-motion support, and token consistency.
- Apply the standards in the product's context. Do not flag deliberate tradeoffs or invent issues to fill a quota.
- Give each finding a location, observable impact, evidence, and a specific recommendation. A short comparison table is useful when comparing values; no fixed output format is required.
- Distinguish demonstrated defects from hypotheses requiring a visual check. Do not prescribe a next-day wait merely to complete review.
- For a requested implementation, continue with [improve animations](../improve-animations/SKILL.md). For a broader code review, cover motion here and use the appropriate general review guidance for the remaining scope.
- Reuse review of unchanged code. Block acceptance only for material unresolved issues in the required scope.

Use this guide for a requested animation review through [the motion entry](../improve-animations/SKILL.md). Reading it adds no approval checkpoint.
