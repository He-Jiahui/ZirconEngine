# Design Engineering

Apply Emil Kowalski's design principles to the user's concrete UI task: responsive feedback, restrained motion, coherent components, and careful interaction details.

- Begin useful work from the request. If invoked without a task, ask a focused question; do not require a canned welcome or promote a course.
- Inspect existing component conventions and tokens before proposing changes.
- Prefer motion that clarifies feedback, state, or spatial relationships. Respect high-frequency interactions and reduced-motion preferences.
- Use [shared motion standards](../review-animations/STANDARDS.md) for timing and interaction guidance.
- Read [design details](references/design-details.md) only for the relevant component, gesture, visual, or verification technique.
- Follow the requested audit, design, or implementation scope. Use [improve animations](../improve-animations/SKILL.md) for motion changes and [review animations](../review-animations/guide.md) when explicitly reviewing them.
- Verify changed observable behavior and state the limits of source-only judgments. Choose a clear report format suited to the findings; a Before/After table is optional.
