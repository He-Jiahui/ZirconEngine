# Choose a skill layout

Keep a small skill flat. Give an independently invocable workflow its own `SKILL.md` and valid frontmatter; place optional examples and longer guidance in ordinary reference files.

Use `index.md` for categories and reference-only branches. Add a routing skill only when skill selection itself is a useful user-facing workflow.

Link related files from the appropriate entry, use one authority for each policy, and update the generated Codex catalog through its helper. See [scaffolding](scaffold-indexed-skill/index.md).
