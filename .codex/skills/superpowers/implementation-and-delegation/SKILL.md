# Implementation And Delegation

## Progressive Disclosure Index

- Read `test-driven-development/` for test-first feature or bugfix work.
- Read `using-git-worktrees/` when the task needs isolated workspace setup and the repository policy allows worktrees.
- Read `dispatching-parallel-agents/` when multiple independent tasks can proceed in parallel.
- Read `subagent-driven-development/` when executing an implementation plan with delegated subtasks.
