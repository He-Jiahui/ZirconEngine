# Development Techniques

Supporting techniques for an authorized task. Use the repository's delivery and validation policies; select a technique when it adds evidence or structure to the current operation.

| Current need | Guidance |
| --- | --- |
| Execute a written approved plan | [Plan execution](foundations-and-planning/executing-plans/guide.md) |
| Design a useful failing regression | [Test driven work](implementation-and-delegation/test-driven-development/guide.md) |
| Delegate independent work when permitted | [Parallel ownership](implementation-and-delegation/dispatching-parallel-agents/guide.md) or [implementation handoffs](implementation-and-delegation/subagent-driven-development/guide.md) |
| Investigate a defect with an unclear cause | [Debugging skill](review-and-stabilization/systematic-debugging/SKILL.md) |
| Review substantial or risky changes | [Review brief](review-and-stabilization/requesting-code-review/guide.md) |
| Evaluate and address review feedback | [Review feedback](review-and-stabilization/receiving-code-review/guide.md) |
| Decide what verified evidence supports | [Verification](review-and-stabilization/verification-before-completion/guide.md) |

These techniques do not create extra approval checkpoints, mandatory agents, or repeated test runs. Reuse unchanged evidence and complete the requested scope.
