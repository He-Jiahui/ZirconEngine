# Review And Stabilization

## Progressive Disclosure Index

- Read `systematic-debugging/` when the task is diagnosing bugs or failures.
- Read `requesting-code-review/` when the task is asking for review before merge or completion.
- Read `receiving-code-review/` when responding to review feedback.
- Read `verification-before-completion/` before claiming success or completion.

## Scope

- This branch covers correctness, review, debugging, and closeout.
