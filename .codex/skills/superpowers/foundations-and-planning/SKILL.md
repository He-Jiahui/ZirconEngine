# Foundations And Planning

## Progressive Disclosure Index

- Read `using-superpowers/` when the task is about bootstrapping skill usage for a session.
- Read `brainstorming/` when the task needs ideation before implementation.
- Read `writing-plans/` when the task needs a multi-step execution plan.
- Read `executing-plans/` when there is already a written plan to carry out.
