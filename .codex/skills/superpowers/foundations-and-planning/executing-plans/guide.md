# Executing Plans

Execute an existing approved plan within its scope and explicit checkpoints.

1. Read the plan and the code or evidence needed for the next dependency-ready step. Reuse unchanged context already read.
2. Resolve routine implementation choices from the task and repository conventions. Raise only a material ambiguity, and continue unaffected steps.
3. Follow [the shared execution loop](../../../zircon-project-skills/continuous-milestone-execution/execution-loop/index.md) and the owning repository's validation cadence.
4. Track actual completion and remaining dependencies using available task capabilities. A specific planning tool name is not a prerequisite.
5. Stop at a user-requested review/approval boundary; otherwise continue until the authorized plan scope and its required checks are complete.

Delegation is optional and must be permitted by the current environment. If used, follow [model selection](../../../zircon-project-skills/cross-session-coordination/references/model-tier-policy.md) and assign bounded ownership. Do not create another user-visible task merely because a plan is being executed.
