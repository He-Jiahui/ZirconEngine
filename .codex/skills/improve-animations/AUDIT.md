# Motion audit categories

Use [the shared motion standards](../review-animations/STANDARDS.md) for detailed guidance and example values. The audit lens covers purpose/frequency, easing/duration, origin/physicality, interruption, performance, accessibility, consistency/tokens, and useful missing feedback.

Apply only categories relevant to the requested scope. Confirm findings with current code and appropriate visual evidence. Values are starting points to reconcile with product tokens and behavior, not a reason to replace a deliberate correct design.
