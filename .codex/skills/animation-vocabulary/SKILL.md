# Animation Vocabulary

Match what the user sees or feels to [the glossary](references/glossary.md). Search the relevant family rather than reading every entry.

- Lead with the most likely term and one short explanation.
- When several terms fit, give the best match and the distinction that resolves the ambiguity.
- If the description is insufficient or only approximately matches, state that uncertainty.
- Keep a naming answer concise. Route a requested design or implementation to [UI motion](../improve-animations/SKILL.md).
