# Bevy 对齐的 Zircon UI/Text/Widgets/Focus/A11y 里程碑计划

## Summary
- 目标：把 Zircon 的 runtime UI、editor UI、text、standard widgets、styled editor widgets、input focus、UI picking、UI render boundary、a11y 补齐到 Bevy 级别的“能力完成度”，但保持 Zircon-native contract，不克隆 Bevy API。
- 当前基线：Zircon 已有 UI surface/input/render/text/focus/hit/pointer/navigation 基础，例如 [UiFocusState](<E:/Git/ZirconEngine/zircon_runtime_interface/src/ui/surface/focus_state.rs:1>)、[UiSurfaceInputState](<E:/Git/ZirconEngine/zircon_runtime/src/ui/surface/input/state.rs:1>)、[extract_ui_render_tree](<E:/Git/ZirconEngine/zircon_runtime/src/ui/surface/render/extract.rs:1>)；tracked 文件中未发现 a11y/accessibility/accesskit 实现。
- Bevy 本地源码基线：`dev/bevy` `main`，commit `c040d7603`，`git describe` 为 `v0.16.0-rc.4-2455-gc040d7603`。公开文档引用以 docs.rs/bevy.org 当前 `0.18.1` 页面为准。
- 架构默认：`zircon_runtime_interface` 定义合同，`zircon_runtime` 执行 UI 行为/布局/文本/a11y/render extract，`zircon_editor` 只消费共享合同与 styled widgets；不新增非网络 `server` 层，不把 editor 私有逻辑作为 runtime truth。

## Milestones
1. **M0 Evidence & Gap Audit**：建立 Zircon ↔ Bevy 对照矩阵，覆盖 UI schedule、focus、picking、text、widgets、Feathers、a11y、render extract；输出缺口表、目标测试表、现有 docs 需更新列表。
2. **M1 Contract Spine**：先在 `zircon_runtime_interface` 固化 focus/pick/navigation/widget/a11y/render DTO，不改 editor 行为；schema 校验所有新字段可序列化、可向后默认。
3. **M2 Runtime Input Focus Core**：实现 Bevy `InputFocus` 等价资源、focus visible、focus gained/lost、focused input bubbling、autofocus、hidden/disabled/despawn 清焦点；测试初始焦点、多次变更、鼠标/键盘焦点可见性。
4. **M3 Tab & Directional Navigation**：实现 `TabGroup`/`TabIndex`、modal group trap、Shift-Tab、方向导航与手动 override；比 Bevy 多纳入 surface/layer/z-order，避免 editor 浮窗和 viewport overlay 乱序。
5. **M4 UI Picking & Pointer Route Convergence**：统一 runtime hit grid、editor viewport overlay route、UI node route；定义 `UiPickPolicy` 同时服务 hover/click/focus/a11y，修正 Bevy picking backend 与 `FocusPolicy` 分裂的问题；测试重叠、clip、scroll、popover、scene gizmo 与 UI overlay 竞争。
6. **M5 Headless Standard Widgets**：实现 Button/IconButton、Checkbox、RadioGroup、Slider、Scrollbar、TextInput/EditBox、Menu/MenuItem、Popover、Tooltip 的无样式行为层；键盘与 pointer 触发同一事件，disabled/pressed/cancel/value clamp 行为可测。
7. **M6 Text To Bevy-Level**：引入 `UiTextShaper` 抽象，目标实现采用 Parley/Swash 级别能力；补齐富文本 runs、字体 fallback、测量参与布局、grapheme/word editing、selection、cursor blink、clipboard、IME、multiline、filter/max chars。
8. **M7 UI Schedule & Dirty Pipeline**：形成固定阶段：InputCollect → Focus → WidgetBehavior → TextMeasure → Layout → PostLayout/Stack → Picking → A11yExtract → RenderExtract → BatchPrepare；每阶段输出 dirty/report，避免鼠标移动触发整树重建。
9. **M8 Render Boundary**：runtime 只输出接口层 render extract，WGPU runtime 与 Slint/editor painter 都消费同一 DTO；覆盖 background/border/image/material/gradient/shadow/text/selection/cursor/debug overlay、clip/scissor、batch split reason。
10. **M9 Accessibility Runtime**：生成 `UiAccessibilityTreeSnapshot`，映射 role/name/state/action/bounds/parent-child；name 来源优先级为显式 a11y name、label-for、文本内容、tooltip；action 回流为 widget event。
11. **M10 Feathers-like Styled Editor Widgets**：在 headless widgets 上构建 Zircon editor widget kit 与 theme tokens，覆盖 toolbar、inspector、tabs、menus、dock header、property row、color controls、search/text input、tooltip/popover；样式不 fork 行为。
12. **M11 Editor Cutover & Productization**：逐步把 workbench、asset editor、inspector、drawer、floating window、viewport toolbar、menus 迁到共享 focus/picking/widgets/a11y/render 合同；删除重复的局部 hover/popup/focus 路由。
13. **M12 Docs & Acceptance**：更新 `docs/ui-and-layout`、`docs/zircon_runtime/ui`、`docs/zircon_runtime_interface/ui`、editor UI 文档；每个里程碑记录 Bevy 源码依据、Zircon 实现文件、测试命令和未决限制。

## Test Plan
- Contract tests：新 DTO/schema 默认值、serde roundtrip、旧 `.ui.toml` 不破坏、缺失 a11y name 产生诊断。
- Focus/navigation tests：Tab/Shift-Tab、方向键、modal popover trap、despawn/hide/disable 清焦点、focus visible、focused input bubbling。
- Picking tests：重叠节点、pass/block/transparent/no-event、clip/scroll/text hit、pointer capture、release outside、viewport gizmo 与 UI overlay 优先级。
- Widget tests：Button activate、Checkbox/Radio value change、Slider clamp/step、Menu open/close/ESC/outside click、TextInput 编辑/选择/clipboard/IME 请求。
- Render/text tests：text measure 与 layout 一致、selection/cursor extract、batch key 分裂、debug overlay、dirty domains、字体 fallback、grapheme 删除。
- A11y tests：tree snapshot、role/state/action、bounds、focus update、hidden/disabled 处理、action 回流 widget event；editor 截图/交互 golden 覆盖主工作流。
- Validation default：里程碑内跑 `cargo test -p zircon_runtime_interface`、`cargo test -p zircon_runtime --lib ui`、`cargo test -p zircon_editor --lib ui` 的相关子集；最终阶段再跑可承受的 workspace/CI parity 验证并归档失败项。
